# 节点43：退出策略

> **面向OPC**：不是每个项目都要做一辈子。知道什么时候该坚持、什么时候该放手、什么时候该卖掉——这是OPC最重要的决策能力之一。本节点告诉你2026年OPC的四种退出方式。

---

## 一、退出不是失败

### 先纠正一个认知

| 你以为的退出 | 实际上的退出 |
|---|---|
| 失败、放弃、丢人 | 资源重新配置、止损、为下一个项目腾出精力 |
| 项目死了 | 经验留下了 |
| 白干了 | 你用X个月买了一个别人没有的经验 |

**2026年最成功的OPC们，平均经历过2.3个"失败"项目才找到那个赚钱的。**

---

## 二、四种退出方式

### 方式1：关停（最快，最常用）

**什么时候该关停**：

| 信号 | 标准 |
|---|---|
| 连续亏损 | 6个月总收入<总支出 |
| 用户不增长 | 连续3个月月活无增长 |
| 你不想做了 | 打开代码都觉得痛苦（持续1个月以上） |
| 更好的机会来了 | 有一个明确更赚钱/更有意义的方向 |

**关停的正确姿势**：

1. 给现有用户发一封邮件/公告："XX产品将于X月X日停止服务。数据可在X月X日前导出。感谢你的支持。"
2. 导出所有数据备份（留作纪念和复盘）
3. 写一篇复盘文章：《我做了X个月的产品为什么失败了》→ 这篇文章可能比你产品赚得还多（行业内有大量失败复盘文章的阅读量>10万）

### 方式2：卖掉（最赚钱，最难）

**2026年OPC产品能卖多少钱**：

| 产品状态 | 估值范围 | 在哪卖 |
|---|---|---|
| 有用户无收入 | ¥5000-20000 | Acquire.com, 即刻/推特发帖 |
| 月收入¥1000-5000 | 年收入×1-2倍 | Acquire.com, Flippa |
| 月收入¥5000-20000 | 年收入×2-3倍 | MicroAcquire, 私下 |
| 月收入>¥20000 | 年收入×3-5倍 | 投资人/同行直接联系 |

**2026年OPC产品交易平台**：

- [Acquire.com](https://acquire.com) — 全球最大的小微SaaS交易市场
- [Flippa](https://flippa.com) — 适合内容站/电商/小工具
- 即刻/推特发帖 — 中文独立开发者圈内交易

**卖掉前要准备的**：
- 6个月的收入数据截图
- 用户数和增长曲线
- 技术栈文档（买家要能接手）
- 为什么卖的真实原因（买家会问）

### 方式3：转为副业（最温和）

产品不赚钱但用户还在用 → 不关停，也不全力做。

```
转为副业的操作：
1. 服务器降到最低配置（月费¥24）
2. 关闭需要人工介入的功能（如客服咨询）
3. 设置自动回复："这个产品目前由我一个人维护，回复可能较慢"
4. 每个月花1天看看运行状态
5. 把90%的精力投入下一个产品
```

### 方式4：开源（最有长期价值）

产品不赚钱但对社区有价值 → 开源。

```bash
# 1. 清理敏感信息
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch .env" --prune-empty -- --all

# 2. Push到GitHub Public
git remote add public https://github.com/你的用户名/项目名.git
git push public main

# 3. 写README（为什么做、怎么用、为什么不做了）
# 4. 在V2EX/即刻/推特宣布开源
```

**开源的价值**：GitHub上的开源项目=你的永久技术名片。很多OPC的下一个客户/合伙人，是通过他的开源项目找到他的。

## 三、退出决策框架

```
每个季度问自己一遍：
□ 这个产品还在增长吗？（用户数/收入/我的兴趣）
□ 如果今天重新选择，我还会做这个产品吗？
□ 我花在上面的时间，如果用来做别的，会不会更好？

如果有2个以上"否" → 认真考虑退出。
```

---

## 四、检查清单

- [ ] 已明确当前产品的退出标准（什么时候该关/卖/开源）
- [ ] 产品数据有定期备份
- [ ] 用户数据导出功能可用（关停时用户要能拿走自己的数据）
- [ ] 如果卖：6个月财务数据已整理
- [ ] 如果开源：敏感信息已清理

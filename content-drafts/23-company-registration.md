# 节点23：公司注册与主体选择

> **面向OPC**：你想合法做生意、开发票、接企业客户、保护个人财产。但第一步卡住了——个体户还是有限公司？注册资本填多少？没有办公室能注册吗？

---

## 一、三种主体对比：你到底该办哪种

2026年的选择逻辑已经变了。不再是"便宜vs贵"的注册成本对比，而是**"合规能力 vs 风险偏好"的长期匹配**。

### 一表看懂

| 维度 | 个体工商户 | 一人有限公司 | 一人股份有限公司 |
|---|---|---|---|
| **责任** | 无限责任（个人全部财产兜底） | 有限责任（以出资额为限） | 有限责任（以认购股份为限） |
| **年利润50万税负** | ~21.9%（个体经营所得税） | ~5%（小微企业优惠后） | ~5%（小微企业优惠后） |
| **社保** | 自愿缴纳 | 强制五险（约1500-2500元/月） | 强制五险 |
| **银行开户** | 个人账户即可 | 需对公账户+实地核查 | 需对公账户+实地核查 |
| **注销** | 简易注销，几天完成 | 需清算程序，1-2个月 | 需清算程序，1-2个月 |
| **转让** | 无法转让，只能注销重开 | 股权变更即可 | 股份自由转让 |
| **融资能力** | 无 | 可引入股东 | 标准股份结构，可分期发行 |
| **年维护成本** | ¥0-500 | ¥3000-6000（代账+审计） | ¥5000-10000（代账+审计） |
| **适合** | 副业试水、无企业客户需求 | 想做正规生意的绝大多数OPC | 未来计划融资/股权激励 |

## 二、新公司法关键条款（2024修订·2026年现行有效）

2024年7月1日起施行的新《公司法》对OPC影响最大的三条：

### 1. 五年实缴制（第47条）

**不再是"认缴一个亿、实缴五十块"的时代了。**

全体股东认缴的出资额，必须在公司成立之日起**5年内**缴足。这是硬性规定，没有例外。

**对你的影响**：注册资本不要乱填。填100万 = 5年内要有100万现金进对公账户。

### 2. 一人公司财产独立举证责任（第23条）

> 一人公司股东若不能证明公司财产独立于自己财产的，应当对公司债务承担连带责任。

翻译成人话：**不是债权人证明你混同，而是你自证清白。** 每年必须有完整审计报告，否则有限责任保护伞等于白纸。

### 3. 一人股份有限公司首次合法化（第92条）

新法首次允许设立"一人股份有限公司"。股份可以自由转让、可以分期发行——为未来融资和股权激励预留了标准接口。

## 三、注册资本设定实操指南

### 三种常见金额的实缴现实

| 注册资本 | 5年内实缴压力 | 适合场景 |
|---|---|---|
| **10万元** | 每月存1667元，完全可控 | 最低门槛，满足基本商业信誉 |
| **100万元** | 每月存16667元，对初创有压力 | 需要一定门面（比如竞标要求） |
| **500万元+** | 每月存83333元，极难 | 除非已有明确融资计划，否则强烈不建议 |

### OPC的最佳策略

**初期注册10万元。** 理由：
- 年应纳税所得额 ≤ 300万时，实际企业所得税税率低至5%
- 10万的实缴压力几乎为零（月均1667元）
- 盈利后可随时办理增资扩股

**绝对不要做的事**：为了"看上去厉害"填500万。5年内没缴足，会被列入经营异常名录，严重的可能被吊销执照。

## 四、注册全流程：七步拿到营业执照

### 步骤1：核名自主申报（约10分钟）

**官方入口**：各省市"企业开办一网通办"平台

| 地区 | 官方办理地址 |
|---|---|
| **全国统一** | [国家企业信用信息公示系统](https://www.gsxt.gov.cn) |
| **北京** | [北京市企业服务e窗通](https://ect.scjgj.beijing.gov.cn) |
| **上海** | [上海市一网通办](https://zwdt.sh.gov.cn) → 企业开办专区 |
| **广东（含深圳）** | [广东省政务服务网](https://www.gdzwfw.gov.cn) → 企业开办 |
| **浙江** | [浙江政务服务网](https://www.zjzwfw.gov.cn) → 企业开办 |
| **江苏** | [江苏省政务服务网](https://www.jszwfw.gov.cn) → 企业开办 |
| **四川** | [四川政务服务网](https://www.sczwfw.gov.cn) → 企业开办 |
| **其他省份** | 搜索"XX省/市 企业开办一网通办" |

名称结构：**行政区划 + 字号 + 行业 + 组织形式**

示例：`北京 智远 科技有限公司`

- 字号：你起的名字（准备3-5个备选，系统自动查重）
- 行业：从系统标准行业库中点选（不要自己造词）
- 组织形式：一人有限责任公司 / 一人股份有限公司

### 步骤2：确定公司核心要素（约30分钟）

这步需要确定几件事，在线上填报时会用到：

**① 公司类型**：绝大多数OPC选"一人有限责任公司"

**② 经营范围**：通过标准化条目库点选，不要自己写
- 首项：主营业务（比如"软件开发"）
- 不要贪多——太杂反而影响后续资质申请
- 提示：数字文化经营许可证、增值电信业务许可证对应的经营范围，需要单独列出

**③ 注册资本**：10万元

**④ 法定代表人**：你自己

**⑤ 监事**：需要另一个人（不能是法定代表人自己）。可以请家人或朋友担任，只是挂名，不承担实际责任

### 步骤3：在线填报与实名认证（约1小时）

在各省"一网通办"平台完成：

1. 上传身份证正反面照片
2. 选择并修改《公司章程》模板（平台提供标准模板，OPC无需自己写）
3. 完善"股东职权行使"条款
4. 股东、法定代表人、监事通过手机APP完成**人脸识别 + 电子签名**

### 步骤4：电子签署并提交

所有人员在APP上完成电子签名后，系统自动提交至市场监督管理局。审核通常**0.5个工作日**完成。

### 步骤5：领取电子营业执照

审核通过后：
- **电子执照**：通过微信/支付宝"电子营业执照"小程序即时下载（与纸质执照同等法律效力）
- **纸质执照**：可选择邮寄或现场领取

### 步骤6：免费刻章

大多数城市为新注册企业提供**免费刻章服务**（公章、财务章、法定代表人章、发票章）。在"一网通办"平台提交注册申请时勾选即可。

### 步骤7：税务登记 + 银行开户

- **税务登记**：取得营业执照后30日内完成。现在多数城市已实现"注册即登记"，执照下来时税务登记已自动完成
- **银行开户**：携带执照、公章、法人身份证到银行办理对公账户。详见节点44（银行开户与商户号）

**全程时间**：材料齐全的情况下，从提交申请到拿到执照 —— **1个工作日**。

## 五、注册地址方案

没有实体办公室也能注册公司，2026年有三种主流方案：

| 方案 | 年成本 | 优点 | 银行开户 |
|---|---|---|---|
| **集群注册/托管地址** | ¥1000-3000/年 | 成本最低，政府背书孵化器 | ⚠️ 需确认银行是否接受 |
| **共享办公/孵化器工位** | ¥3000-8000/年 | 有实际工位，开户无障碍 | ✅ 可行 |
| **住宅地址** | ¥0 | 零成本 | ❌ 多数银行不接受 |
| **实体租赁** | ¥30000+/年 | 无任何限制 | ✅ 完全可行 |

### OPC实战建议

**首选**：当地人社局、高新区、产业园区的**政府背书创业孵化器**。通常¥2000-4000/年，包含工位使用权，银行开户无障碍。

**各地孵化器查询入口**：
- [科技部火炬中心·国家级孵化器名录](https://www.chinatorch.gov.cn)
- 搜索"XX市 创业孵化器 工位出租"
- 各市人社局创业指导中心（可直接电话咨询）

**关键提醒**：在任何托管地址方案下注册前，务必先向**当地市场监督管理局**和**目标开户银行**确认：该地址是否在有效白名单内、是否可用于对公账户开户。部分地区要求"一址一照"。

## 六、注册后立即要做的三件事

### 第一件：财产隔离（注册当天）

**核心铁律：公司账户与个人账户必须完全分离。**

所有经营收入必须先进入公司对公账户，再通过正规渠道（工资、分红）提取至个人卡。哪怕是一笔¥50元的收款，也必须走对公账户。

合法提取方式：
- **发工资**：签劳动合同，依法代扣个税
- **分红**：需有书面股东决定书
- **借款**：签借款协议，约定还款期限和利率

一旦被法院认定财产混同，有限责任保护伞即时失效——你将用全部个人财产承担公司债务。

### 第二件：书面决定记录（从第一天开始）

新《公司法》第60条：一人有限责任公司不设股东会。股东作出决定时，**必须采用书面形式**，签名后置备于公司。

**必须记录的八件事**：
1. 利润分配方案
2. 增减注册资本
3. 修改公司章程
4. 对外投资或担保
5. 变更经营范围
6. 变更注册地址
7. 对外重大合同签署
8. 大额采购决策

建议建一个文件夹，每次做决定时写一句："本人XXX，作为XX公司唯一股东，就[事项]作出如下决定：[内容]。签名+日期"，拍照存手机里。

### 第三件：年度合规日历

| 时间 | 事项 | 后果（不做） |
|---|---|---|
| **每年1-5月** | 企业所得税汇算清缴 | 滞纳金+罚款 |
| **每年3-6月** | 工商年报公示 | 经营异常名录（贷款/投标全废） |
| **每年5月** | 个人所得税综合所得汇算 | 滞纳金 |
| **每两年** | 年度审计报告 | 失去有限责任保护 |
| **注册后立刻** | 申请创业补贴 | 错失¥5000-20000 |

**创业补贴提醒**：注册后主动对接当地人社局。大多数城市为首次创业的大学生/退役军人/失业人员提供一次性创业补贴¥5000-20000元，以及免息创业担保贷款。

## 七、OPC避坑：刺破有限责任的五把刀

以下五种情形，法院将"刺破公司面纱"，让你承担无限连带责任：

| 触发情形 | 你的防线 |
|---|---|
| **① 公私账户混同** | 对公账户只进不出，每月给自己发固定工资 |
| **② 无年度审计报告** | 每两年至少做一次审计（费用约¥2000-3000） |
| **③ 公司资产个人使用** | 公司买的电脑就是公司的，不要搬回家拆了打游戏 |
| **④ 经营与消费捆绑核算** | 公司的钱不付家里的水电费，反之亦然 |
| **⑤ 以个人名义签合同、公司受益** | 所有经营合同必须以公司名义签署 |

**三道防火墙**：
1. **干净的银行流水**（100%可追溯）
2. **完整的会计凭证**（每笔进出有发票/合同匹配）
3. **连续的审计报告**（建议每两年审计一次）

**控制成本建议**：公司注册后，找一家代理记账公司（¥200-400/月），确保一切合规。

## 总纲

执照只是起点。完成公司注册，你获得的不只是一张营业执照，更是一套OPC创业的合规生存框架。

**选主体四步法**：
1. 看责任：能接受无限责任吗？→ 个体户
2. 看税负：年利润预期多少？→ 超过10万选有限公司
3. 看客户：有企业客户吗？→ 必须有限公司（个体户不能开专票）
4. 看未来：有融资/转让计划吗？→ 一人股份有限公司

> 把公司视为独立的生命体。用规范的财产管理、书面决策和财税记录来喂养它，它就能用有限责任为你承担商海风浪。

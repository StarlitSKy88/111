# 节点26：审核材料准备

> **面向OPC**：产品要在平台上发布（App Store、微信小程序、应用市场），审核是第一道关卡。审核不通过 = 你的产品见不到用户。本节点告诉你：不同平台审什么、怎么准备材料一次过。

---

## 一、你需要通过哪些审核？

| 你的产品形态 | 需要过的审核 | 审核周期 | 难度 |
|---|---|---|---|
| **Web网站** | 无需审核（直接上线） | 0天 | ⭐ |
| **微信小程序** | 微信小程序审核 | 1-7个工作日 | ⭐⭐ |
| **iOS App** | App Store审核 | 1-3个工作日 | ⭐⭐⭐ |
| **安卓App** | 各应用市场审核 | 1-5个工作日 | ⭐⭐ |
| **支付功能** | 微信/支付宝商户审核 | 1-5个工作日 | ⭐⭐ |

---

## 二、微信小程序审核（国内OPC最常遇到的）

### 审核看什么（2026年微信审核规则）

1. **类目匹配**：你的小程序选的类目必须和实际功能匹配。工具类不能选社交类，选了会被拒。
2. **资质齐全**：涉及商业/支付/社交等类目，需要上传对应的许可证或资质证明。
3. **功能完整**：提交审核时小程序不能是"空壳"。必须有可交互的功能。
4. **无诱导分享**：不能有"分享到群才能用""转发得红包"等诱导行为。
5. **用户协议+隐私政策**：必须有，且必须在用户使用前弹窗展示。

### 准备材料清单

| 材料 | 在哪获取 |
|---|---|
| 小程序名称+简介+图标 | 你自己准备（图标1024×1024px） |
| 小程序截图（至少3张） | 小程序内操作截图 |
| 测试账号（如需登录） | 提供一个测试用的微信号/手机号 |
| 营业执照（企业小程序） | 工商局/电子营业执照 |
| 特殊行业资质（如需要） | 对应主管部门 |

### 一次过的技巧

> **提交审核前，用微信官方的"小程序开发助手"自查。** 它能检测出大部分格式问题。

## 三、App Store审核（如果做iOS）

### 最容易被打回的5条

| 打回原因 | 预防 |
|---|---|
| **功能不完整** | App不能只是一个网页壳（WebView套壳） |
| **缺少隐私政策** | 必须在App内有隐私政策入口 |
| **要求不必要的权限** | 不要一上来就要通讯录/相册权限 |
| **UI太差** | 苹果对设计有最低美学要求 |
| **隐藏功能** | 不能有审核时看不到的功能（如隐藏支付） |

### 必备材料

- 开发者账号（$99/年）
- App图标（1024×1024px）
- App截图（iPhone 5.5寸和6.5寸各一组，至少3张）
- 隐私政策URL
- 测试账号

## 四、审核材料模板（通用）

### 产品介绍文案（每个平台都需要）

```
产品名称：OPC节点百科
一句话介绍：一个人，57个节点，从零到赚钱。
目标用户：想一个人创业的独立开发者/自由职业者
核心功能：
  1. 57个创业节点导航 — 从想法到赚钱的完整路径
  2. OPC适配度测试 — AI分析你是否适合一人创业
  3. AI内容生成 — 每个节点自动生成详细指南
```

### 测试账号信息（每次审核都需要）

```
测试账号：test@opcone.com
密码：Test123456
测试环境：https://你的域名.com
注意事项：如果登录态过期，重新登录即可。
```

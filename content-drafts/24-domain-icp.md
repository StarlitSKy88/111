# 节点24：域名购买与ICP备案

> **面向OPC**：产品做好了，但你的网址还是 `localhost:3000`。现在你需要一个正式的域名，并且让你的网站合法地在中国大陆被访问。两步走：买域名 → 备案。全程一个人可以搞定。

---

## 一、域名购买（10分钟）

### 2026年推荐注册商

| 平台 | 优势 | .com价格/年 |
|---|---|---|
| **阿里云（万网）** | 国内最大，备案流程最顺滑 | ¥75 |
| **腾讯云** | 如果你用腾讯云服务器，备案方便 | ¥75 |
| **Cloudflare** | 隐私保护免费（隐藏注册人信息） | $10.44 |
| **Namecheap** | 海外老牌，UI简单 | $14 |

**OPC建议**：如果服务器在国内（阿里云/腾讯云）→ 域名也在同一平台买，备案一站式。如果服务器在海外（Vercel）→ 域名在哪买都行。

### 域名选择三原则

1. **短**：≤10个字符（不含后缀），好记好打
2. **拼音/英文**：不要中英文混（如"wo的网站.com"）
3. **.com优先**：.com是用户默认输入的认知。如果.com被注册了，选.cn或.cc，但别选.xyz/.top（给人不正规感）

### 一个省心操作

**注册10年**（或者最长年限）。域名到期忘记续费 = 网站挂掉 + 被别人抢注。一年的域名费还不够一顿火锅，别省这个。

## 二、ICP备案：最让OPC头疼但必须做的事

### 先搞清楚：你需要备案吗？

```
你的服务器在国内（阿里云/腾讯云等）？
  ├─ 是 → 必须备案。不备案 = 服务商会阻断访问
  └─ 否（Vercel/Netlify/海外VPS）
      ├─ 用户全在国内 → 建议备案（速度快），但技术上不强制
      └─ 用户有海外 → 不需要
```

### 备案全流程（2026年现状）

| 步骤 | 做什么 | 耗时 | 在哪做 |
|---|---|---|---|
| 1. 买服务器 | 买一台轻量应用服务器（最便宜的就行） | 5分钟 | 阿里云/腾讯云控制台 |
| 2. 提交备案 | 填写主体信息+网站信息 | 30分钟 | 服务器商的备案系统 |
| 3. 人脸核验 | 用手机扫码做人脸识别 | 2分钟 | 阿里云/腾讯云App |
| 4. 等待初审 | 服务商先审核你的材料 | 1-2个工作日 | - |
| 5. 短信核验 | 收到工信部短信，点链接确认 | 1分钟 | 手机短信 |
| 6. 等待管局审批 | 各省通信管理局最终审核 | 3-20个工作日 | - |
| 7. 备案完成 | 获得备案号（如"京ICP备XXXXXXXX号"） | - | - |

### 备案材料清单（个人备案）

| 材料 | 要求 |
|---|---|
| 身份证 | 正反面彩色扫描/拍照 |
| 本人现场照片 | 备案App人脸识别 |
| 域名证书 | 域名注册商后台下载 |
| 网站名称 | 不能带"中国""中华""国家"等字样，不能和备案主体无关 |

**OPC注意**：个人备案的网站不能涉及企业/商业/电商/论坛/社交。如果你做的是商业产品 → 先用个体户或公司备案（参考节点23）。

## 三、备案通过后的必做操作

### 1. 网站底部加备案号

```html
<footer>
  <a href="https://beian.miit.gov.cn">京ICP备XXXXXXXX号</a>
</footer>
```

**不加 = 违规。** 管局会抽查。

### 2. 公安联网备案（部分地区要求）

备案通过后30天内，在 [www.beian.gov.cn](https://www.beian.gov.cn) 做公安备案。会得到一个"京公网安备XXXXXXXX号"，同样需要挂在网站底部。

### 3. 配置HTTPS

备案通过 → 域名解析生效 → 立刻申请SSL证书（节点25会讲）。

## 四、常见翻车

| 翻车 | 原因 | 避免 |
|---|---|---|
| 备案被拒 | 网站名称带"中国"或与实际内容不符 | 用你产品的真实名字，不加修饰词 |
| 备案被拒 | 个人备案但网站内容明显是商业经营 | 注册个体户用企业备案 |
| 备案周期拉长 | 材料有问题被打回重审 | 提交前让服务商客服先看一遍 |
| 域名过期导致备案注销 | 备案后域名过期未续费 | 域名续费10年，设闹钟提前30天 |

# opcone / structure

## 目录结构
```
opcone/
  index.html          # 自测题首页（10道题）
  app.js              # 主逻辑
  questions.json      # 题库
  nodes/
    01-opc-fit-test/   ...   57-government-policy/
      index.html       # 每个节点独立页面
```

## 节点命名
格式：`XX-slug/index.html`，如 `45-tax-invoice/index.html`

## 节点模板结构
固定侧边栏 TOC + 固定顶部导航 + 文章内容区

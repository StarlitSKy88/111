# opcone / tech_stack

## 技术栈
- 原生 HTML + CSS + JavaScript（无框架）
- Tailwind CDN（部分页面）
- Google Fonts：Noto Serif JP、Noto Sans SC
- html2canvas + jsPDF（PDF/分享卡生成）

## 版本
- Tailwind CDN：latest
- html2canvas：1.4.1
- jsPDF：2.5.1

## 依赖文件
- `index.html` — 自测题首页
- `app.js` — 主逻辑（状态机 + 渲染函数）
- `questions.json` — 自测题数据
- `/nodes/<XX>-slug/index.html` — 节点模板（57个）

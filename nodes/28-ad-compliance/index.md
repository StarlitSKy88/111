2026年是中国广告监管最严的一年。《互联网广告管理办法》全面实施，各平台（抖音、微信、小红书）对广告内容审核越来越严格。违规广告的后果不只是封号——可能面临几十万到几百万的罚款。本节点详解广告合规的核心红线，避免踩坑。

### 详细说明

#### 一、广告法核心红线

**1.1 绝对禁止用语**

以下词语在广告中绝对禁止使用：

| 类别 | 禁用词 |
|:---|:---|
| **绝对化** | 最、第一、顶级、顶级、唯一、第一品牌 |
| **虚假承诺** | 无效退款、保证治愈、100%有效 |
| **虚假数据** | 数据无来源、虚构统计结果 |
| **权威虚假** | 冒充国家机关、名人代言未授权 |
| **色情低俗** | 擦边内容、过度性暗示 |

**1.2 特殊行业禁止词**

| 行业 | 禁用表达 |
|:---|:---|
| **医疗** | 最高级治愈率、保证疗效、虚假案例 |
| **金融** | 承诺收益、无风险、保本 |
| **教育** | 第一名、保证提分、押中原题 |
| **房产** | 投资回报、升值承诺 |

**1.3 违规处罚标准**

| 违规类型 | 处罚 |
|:---|:---|
| 虚假广告 | 广告费用3-5倍罚款，最低1万元 |
| 绝对化用语 | 20-100万元罚款 |
| 医疗虚假广告 | 100-500万元罚款 |
| 情节严重 | 吊销营业执照 |

#### 二、各平台广告规范

**2.1 抖音广告规范**

- **医疗健康**：需要资质认证，功效声称需有依据
- **金融**：不能承诺收益，不能用"保本"等词
- **教育培训**：不能出现"保证就业"、"押题"等
- **酒类**：禁止未成年人形象，禁止"喝了能"等功效暗示

**2.2 微信朋友圈广告规范**

- 不能使用领导人或国家机关形象
- 不能使用"国家级"、"最高级"等用语
- 不能有虚假降价信息（先涨后降）
- 必须标注"广告"字样

**2.3 小红书广告规范**

- 商业广告需标注"赞助"、"广告"
- 不得伪造用户评价（素人广告需标注）
- 功效声称需要成分/数据支撑
- 不得贬低竞品

#### 三、广告合规实操

**3.1 广告文案检查清单**

- [ ] 没有"最"、"第一"、"顶级"等绝对化词
- [ ] 没有"无效退款"、"保证治愈"等虚假承诺

**3.2 广告审核流程**

| 步骤 | 动作 |
|:---|:---|
| 自查 | 按检查清单逐项核对 |
| 平台预审 | 提交前在平台创意中心预审 |

**3.3 遇到违规警告怎么办**

1. **立即停止**：不要再投放该广告
2. **分析原因**：看警告是什么类型的违规
3. **修改素材**：调整文案或图片
4. **重新提交**：确认合规后再投放
5. **申诉**：如果认为判断有误，可以申诉

#### 四、特殊场景合规

**4.1 代言人合规**

- 名人代言需要签署真实使用承诺
- 不能使用未授权的他人形象
- 特殊行业（医疗、金融）需要资质

**4.2 价格标示合规**

- 标注原价和促销价
- 原价需要真实（不能虚构）
- 促销时间要明确

**4.3 跨境电商广告合规**

- 进口产品需要中文标签
- 不能宣传"海外直邮"但实际国内发货
- 成分描述需要符合中国法规

### 常见问题

**Q1: "最"字真的不能用吗？**

A: 是的。"最"字属于绝对化用语，违反《广告法》第九条。可以用"领先"、"深受好评"等替代。

**Q2: 客户案例能不能用？**

A: 可以，但需要：① 真实客户授权；② 数据真实可查；③ 不能夸大效果。

**Q3: 朋友圈发的产品介绍算广告吗？**

A: 如果带有推广性质（如引导购买），就属于广告，需要标注"广告"。即使是真实使用分享，如果有明确的购买引导，也可能被认定为广告。

**Q4: 收到平台违规通知怎么办？**

A: 立即停止投放 → 分析违规原因 → 修改素材 → 申诉或重新提交。避免重复违规，否则账户可能被封。

**Q5: 广告合规需要咨询律师吗？**

A: 高风险广告（医疗、金融、教育）投放前建议咨询律师。普通广告只要避免绝对化用语和虚假承诺，一般问题不大。

**Q6: 怎么判断我的广告是否违规？**

A: ① 使用平台提供的预审工具；② 对照广告法检查清单；③ 让没有利益关系的人看是否觉得夸大。

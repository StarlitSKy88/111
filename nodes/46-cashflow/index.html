现金流与财务基础

一人公司没有投资人兜底。现金流就是你还能活多久的倒计时器。本章不讲会计学原理，只讲三件事——你的钱在哪儿、还能撑多久、什么时候能辞职全职干。

二、现金跑道：你还能活多久

公式

现金跑道（月）= 当前存款 ÷ 月固定总支出

月固定总支出 = 公司刚性支出 + 最低生活支出

你的真实月支出 = 你以为的 × 1.3。计算跑道时请乘以1.3的安全系数。

三、盈亏平衡：每个月至少要赚多少

公式

月盈亏平衡点 = 刚性支出 + 弹性支出 + 隐性支出 + 个人生活支出

拆解

类别典型项目OPC月均范围
刚性支出服务器、域名、SaaS工具、代账、注册地址¥1,500-5,000
弹性支出广告投流、外包、付费课程¥1,000-5,000
隐性支出社保、税款预提、设备折旧摊销¥2,000-5,000
个人生活房租、吃饭、交通¥4,000-15,000（视城市）

一线城市OPC：月盈亏平衡约 ¥12,000-20,000
二三线城市OPC：月盈亏平衡约 ¥8,000-12,000

缩减支出的优先级

  1. 先砍弹性支出（广告、课程、外包）
  2. 再砍SaaS订阅（用免费替代、停用测试）
  3. 再砍非必要刚性（换更便宜的注册地址方案）
  4. 绝不砍：代理记账、社保、税款预提

四、"何时能全职"：一套可操作的判断逻辑

辞职全职创业需要同时满足三个条件：

条件一：产品月收入覆盖个人生活支出

你的产品每个月稳定进账 ≥ 你的房租+吃饭+交通。
不是某一两个月，而是看连续6个月的平均值。如果某月¥30,000、下月¥0，不算稳定。

条件二：现金跑道 ≥ 12个月

在零新增收入的情况下，你的存款够你维持12个月的生存。
这12个月的缓冲不是让你躺平，是让你在连续两个月收入为零的时候仍然有试错空间。

条件三：有至少两个收入来源

不要把全部收入押在一个客户或一个产品上。

  • 主产品收入 + 一个副流（咨询/外包/课程）
  • 产品收入 + 存款利息/投资收入
  • 产品对公收入 + 伴侣/家人稳定收入
满足三个条件 → 可以全职。 否则 → 继续兼职验证。

五、三账户隔离：钱的物理防火墙

把公司的钱和个人的钱分开——不是"心理上"分开，是物理上分开。三个独立账户：

账户一：运营账户（对公账户）

所有客户付款进这里，所有业务支出来自这里。

  • 服务器续费、SaaS订阅、外包付款全部从这个账户出
  • 每周核查一次余额，确保覆盖未来30天的预计支出
  • 从运营账户给自己转工资（每月固定一笔），不要随用随转

账户二：储备账户（个人储蓄账户）

"如果明天起零收入，这个账户能撑多久"的答案。

  • 目标金额：8个月的刚性支出 + 个人生活费
  • 达到目标前：每月收入的30-40%强制转入
  • 只进不出，除非遇到真正的生存危机

账户三：税务账户

税款不是"挣到的钱"，是"暂时替你保管的钱"。

每笔收入到账时，立刻将20-25%转入税务账户。季度末缴税时，这笔钱已经准备好了，不会出现"要交5万但账上只有2万"的绝境。

三账户分割比例

账户每笔进账分配用途
运营账户55-65%日常经营支出
储备账户20-25%安全垫积累
税务账户15-20%季度税款预提

六、预收款不是收入：OPC最容易踩的坑

错误认知

"客户付了12000元年费！这个月收入12000！"

正确认知

客户一次付了12个月年费¥12,000。但你每个月交付一次服务——所以你每个月只能确认¥1,000的收入。

  • 到账¥12,000 → 记入"预收账款"（这是负债，不是你的钱）
  • 每月服务交付 → 从预收账款转¥1,000到"已确认收入"
  • 12个月后 → ¥12,000才全部转化为你的收入
⚠ 金税四期警示

金税四期下，开票金额与申报收入自动比对。如果你第一个月就把¥12,000全申报为收入——当月多交税，后面11个月没收入申报触发异常预警。

七、订阅审计：每季度做一次"停用测试"

典型的OPC SaaS账单

工具月费上月打开次数
Cursor Pro$20每天
Claude Max$200每周2次
Notion Plus$100次（改用飞书了）
Canva Pro$132次
某AI出图工具$150次（上月用了一次后就忘了）
某数据分析工具$300次（免费试用后忘记取消）

这个账单里，Notion、AI出图、数据分析工具三个月没打开，每年浪费 (10+15+30) × 12 = $660（约¥4,800）。

停用测试流程

  1. 列出所有订阅的SaaS，标注月费和上月打开次数
  2. 对"上月打开0次"的工具 → 立即暂停
  3. 暂停两周，看业务是否受影响
  4. 两周无感知 → 永久取消
  5. 有影响 → 恢复订阅，但明确它的不可替代价值

九、季度压力测试

每季度末问自己三个问题

  1. 问题一：如果最大客户明天流失，现金跑道还剩多少？
  2. 问题二：如果所有客户的账期延长30天，现金流能否支撑？
  3. 问题三：如果连续两个月零新客户，第三个会发生什么？

任一回答触达红线 → 立刻启动防御

  • 暂停所有非核心SaaS订阅
  • 加速催收应收账款
  • 减少非必需外包
  • 启动副流收入
  • 重新评估价格策略

总纲

OPC的财务系统不需要复杂。你只需要：

层级工具做什么

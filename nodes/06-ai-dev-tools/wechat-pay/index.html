微信支付

国内必备支付能力。微信月活超13亿，微信支付渗透率近100%。如果你面向中国大陆用户，微信支付是绕不开的基础设施。

最后修订：2026年5月14日 · 官方文档：pay.weixin.qq.com
一、核心定位

微信支付是什么

微信支付是腾讯旗下支付品牌，由财付通提供技术支持。与支付宝共同占据中国第三方移动支付超过90%的市场份额。对国内用户来说，微信支付几乎是"默认选项"——打开微信就能付，不需要额外安装任何东西。

核心特点

生态内支付：微信支付内嵌于微信App，用户无需跳出微信即可完成支付，转化路径最短。

超高渗透率：微信月活13.4亿，微信支付绑定用户超8亿。目标用户几乎100%已有微信支付能力。

多种支付场景：JSAPI支付（公众号/小程序）、Native支付（PC网站）、H5支付（移动网页）、扫码支付、APP支付等。

什么时候用微信支付：面向中国大陆用户提供服务，用户主要通过微信访问你的产品。小程序、公众号、微信内H5页面优先选择微信支付。

重要限制

微信支付仅支持中国大陆企业主体。个人开发者、境外企业无法直接申请微信支付商户。如果你是境外主体，需要找第三方聚合支付服务商（如Ping++、NowPay等）来接入。

二、入门准备

申请微信支付商户

前置条件

  • 中国大陆境内注册的企业营业执照（个体工商户也可）
  • 法定代表人身份证
  • 银行对公账户（用于接收结算资金）
  • 已备案的域名（微信支付要求商户 domain verification）
  • 微信公众平台账号（服务号/小程序）

三、支付类型

选择合适的支付方式

微信支付针对不同场景提供了多种支付产品，选择正确的产品能大幅提升支付成功率。

JSAPI支付（公众号/小程序）

在微信内置浏览器或小程序内发起支付。用户点击后自动打开微信支付中间页，全程在微信内完成，转化率最高。

适用场景

微信公众号网页、微信小程序、微信内H5页面

最适合中国境内ToC产品

Native支付（PC网站）

生成预支付订单后，后端返回二维码链接，前端展示二维码供用户扫码支付。适用于PC网站场景。

# Native支付流程 # 1. 后端创建预订单 # 2. 获取二维码链接code_url # 3. 前端生成二维码（使用qrcode.js等库） # 4. 用户用微信扫码支付 # 5. 微信回调通知 + 前端轮询查询

H5支付（移动网页）

适用于在手机浏览器内发起支付。微信会打开一个中间页引导用户跳转。注意：iOS微信内浏览器请使用JSAPI，H5支付在iOS微信内不可用。

H5支付限制

H5支付需要在微信支付商户平台单独申请，且不建议在微信内置浏览器中使用（会被拦截）。如果是微信内H5页面，请使用JSAPI支付。

APP支付手机App内需移动应用资质★★★★

OPC建议：如果你的产品运行在微信内（小程序/公众号），必须用JSAPI支付。如果是PC网站或H5站，根据场景选择Native或H5。

Node.js 接入微信支付

微信支付提供官方SDK（Java/Php/Python/.NET/Node.js），也可以直接调用REST API。这里介绍Node.js原生实现。

微信支付工具函数

// utils/wechatpay.js const crypto = require('crypto'); const axios = require('axios'); const xml2js = require('xml2js'); // 微信支付配置 const WXPAY_CONFIG = { mch_id: process.env.WXPAY_MCH_ID, // 商户号 appid: process.env.WXPAY_APP_ID, // 应用ID api_key: process.env.WXPAY_API_KEY, // API密钥 notify_url: 'https://yourdomain.com/api/wxpay/callback', // 回调地址 }; // 生成随机字符串 function generateNonceStr(length = 32) { return crypto.randomBytes(length).toString('hex').slice(0, length); } // 生成签名 function sign(params, key) { const sortedKeys = Object.keys(params).sort(); const signStr = sortedKeys .filter(k => params[k] !== '' && params[k] !== undefined && k !== 'sign') .map(k => `${k}=${params[k]}`) .join('&') + `&key=${key}`; return crypto.createHash('md5').update(signStr).digest('hex').toUpperCase(); } // 解析XML响应 async function parseXML(xml) { const result = await xml2js.parseStringPromise(xml, { explicitArray: false }); return result.xml; }

// 创建统一下单（JSAPI） async function createJsapiOrder(openid, orderId, totalFee, subject) { const timeStamp = Math.floor(Date.now() / 1000).toString(); const nonceStr = generateNonceStr(); // 统一下单请求参数 const params = { appid: WXPAY_CONFIG.appid, mch_id: WXPAY_CONFIG.mch_id, nonce_str: nonceStr, body: subject, // 商品描述 out_trade_no: orderId, // 商户订单号 total_fee: totalFee, // 金额（分） spbill_create_ip: 'YOUR_SERVER_IP', notify_url: WXPAY_CONFIG.notify_url, trade_type: 'JSAPI', openid: openid, // 用户openid（JSAPI必需） }; // 生成签名 params.sign = sign(params, WXPAY_CONFIG.api_key); // 发送请求 const xmlData = Object.keys(params) .map(k => `<${k}>${params[k]}`) .join(''); const response = await axios.post( 'https://api.mch.weixin.qq.com/pay/unifiedorder', `${xmlData}`, { headers: { 'Content-Type': 'text/xml' } } ); const result = await parseXML(response.data); if (result.return_code === 'SUCCESS' && result.result_code === 'SUCCESS') { // 返回唤起支付的参数 return { prepay_id: result.prepay_id, signType: 'MD5', timeStamp, nonceStr, package: `prepay_id=${result.prepay_id}`, }; } else { throw new Error(result.err_code_des || '创建订单失败'); } }

七、结算规则

资金结算机制

微信支付采用T+1结算机制，商户收款后资金不会立即到账。

T+1 结算

结算周期

T日：用户完成支付的日期

T+1日：微信在次日凌晨对前一日的交易进行清算，资金通常在上午9点至12点间到达商户银行账户

最低结算金额

商户类型最低结算金额
一般企业商户¥1.00
个体工商户¥0.01（部分情况豁免）
特殊行业可能更高，详见商户平台

提现与转账

  • 微信支付商户平台支持自动提现和手动提现
  • 可以设置每日自动提现，将结算资金自动转入指定银行账户
  • 支持服务商分账，可自动将资金分给供应商/合伙人

账单与对账

微信支付提供完整的对账文件，商户可以在商户平台下载每日的交易流水和资金流水。

# 对账文件获取（通过API） # 下载格式：GZIP压缩的CSV文件 # 对账日期（昨日） const yesterday = new Date(Date.now() - 86400000); const dateStr = yesterday.toISOString().slice(0, 10).replace(/-/g, ''); # API路径 https://api.mch.weixin.qq.com/pay/downloadbill?bill_date={dateStr}&bill_type=ALL

资金冻结

如果商户交易存在异常（用户投诉、涉嫌欺诈、风控预警等），微信可能会对资金进行冻结，延迟结算或扣除异常资金。请确保交易真实合理，保持良好的客诉处理。

八、常见问题

FAQ

Q: 个人开发者可以申请微信支付吗？

A: 不能。微信支付仅对在中国大陆注册的企业、个体工商户开放。如果你是个人开发者或境外主体，只能通过第三方聚合支付服务商（如Ping++、WePay等）间接接入，或者寻找有商户资质的合伙人代收。

Q: 微信支付需要多久才能申请下来？

A: 资料齐全的情况下，审核通常需要1-3个工作日。如果资料有问题需要补充，时间会更长。建议提前准备好所有资料。

Q: 微信支付的回调通知一直收不到怎么办？

A: 首先检查：1）回调URL是否可公网访问；2）是否正确返回了SUCCESS的XML；3）检查商户平台「开发配置」中的回调地址是否正确。如果仍有问题，可使用「交易维权」接口或联系微信支付技术支持。

Q: 支付成功后如何查询订单状态？

A: 有三种方式：1）微信支付商户平台手动查询；2）调用订单查询API；3）接收微信的支付回调通知。推荐以回调通知为主、主动查询为辅的方式。

Q: 微信支付的签名一直验证失败？

A: 签名失败常见原因：1）参数没有按ASCII码排序；2）空值参数没有过滤；3）使用了错误的密钥（注意API密钥和AppSecret是不同的）；4）编码问题（中文需要UTF-8）。

Q: 如何处理重复回调？

A: 微信支付可能对同一笔交易发送多次回调。处理方式：在更新订单状态时检查是否已处理过（幂等性），或者使用数据库事务确保状态更新是原子的。

Q: 微信支付支持海外用户支付吗？

A: 微信支付主要面向中国大陆用户。境外用户如果绑定了中国大陆银行卡可以支付，但体验不稳定。如果你需要服务海外用户，建议同时接入PayPal、Stripe等国际支付方式。

Q: 退款多久到账？

A: 微信支付退款通常是即时处理，资金会在1-7个工作日内原路返回到支付账户（微信零钱或银行卡）。如果超过7天未到账，建议联系微信支付客服。

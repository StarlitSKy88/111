06 / 网络工具

Clash

国内OPC开发必备网络工具。访问GitHub、npm、Anthropic API等海外服务。Clash Verge、ClashX等客户端订阅配置教程。

最后修订：2026年5月14日
一、核心定位

为什么OPC需要Clash

在中国大陆，使用AI编码工具（Claude Code、Cursor）、访问海外服务（GitHub、npm、PyPI）需要特殊的网络连接。Clash是目前最流行的代理工具，支持订阅链接、规则分流、负载均衡。

法律风险提示

根据现行法规，使用VPN工具访问境外服务器存在法律风险。请自行了解相关法规并承担相应责任。本教程仅提供技术说明，不构成使用建议。

OPC的现实：2026年国内网络环境下，不使用任何网络优化工具，几乎无法正常进行AI辅助开发。这是OPC必须面对的基础设施问题。

三、机场订阅

订阅配置

什么是机场

机场是提供代理节点服务的商家。用户通过订阅链接获取节点列表，在Clash中导入订阅后即可使用。

如何获取订阅链接

在机场官网注册账号 → 购买套餐 → 找到"订阅链接"或"Clash配置"复制链接地址。订阅链接格式类似：https://xxx.com/api/v1/client/subscribe?token=xxxxx

添加订阅

# 在Clash Verge中添加订阅 # 1. 配置 → 订阅管理 → 点击 + # 2. 粘贴订阅链接 # 3. 填写名称（如"我的机场"） # 4. 点击保存 # 5. 点击"更新"获取最新节点 # 订阅会自动定时更新（可在设置中配置）

订阅格式

Clash订阅实际上是YAML格式的配置文件。订阅链接返回的内容示例：

# 订阅链接返回内容示例 mixed-port: 7890 allow-lan: false mode: rule rules: - DOMAIN-SUFFIX,github.com,Proxy - DOMAIN-SUFFIX,npmjs.org,Proxy - DOMAIN-KEYWORD,anthropic,Proxy - MATCH,DIRECT proxies: - name: HK-01 type: ss server: hk01.example.com port: 443 cipher: aes-256-gcm password: xxxxx - name: US-01 type: vmess server: us01.example.com port: 443 uuid: xxxxx
四、规则配置

分流规则

Clash支持规则分流，只对特定域名/IP走代理，其他流量直连。这对OPC开发非常重要：

  • GitHub、npm、PyPI 等开发相关域名走代理
  • 国内网站（百度、淘宝）直连，不走代理
  • AI服务（Anthropic、OpenAI）走代理

基础规则类型

规则类型说明示例
DOMAIN-SUFFIX域名后缀匹配github.com 匹配 *.github.com
DOMAIN-KEYWORD域名包含关键词anthropic 匹配 api.anthropic.com
DOMAIN精确域名www.google.com
GEOIPIP地理位置GEOIP,CN 直连中国IP
IP-CIDRIP段10.0.0.0/8
MATCH最后匹配（兜底）其他全部 DIRECT 或 Proxy

推荐开发规则

# Clash Verge → 配置 → 规则设置 # 建议规则顺序： # 1. 国内直连 DOMAIN-SUFFIX,cn,DIRECT DOMAIN-KEYWORD,baidu,DIRECT DOMAIN-KEYWORD,alibaba,DIRECT DOMAIN-KEYWORD,tencent,DIRECT GEOIP,CN,DIRECT # 2. 开发工具 DOMAIN-SUFFIX,github.com,Proxy DOMAIN-SUFFIX,githubusercontent.com,Proxy DOMAIN-SUFFIX,npmjs.org,Proxy DOMAIN-SUFFIX,npx.com,Proxy DOMAIN-SUFFIX,pypi.org,Proxy DOMAIN-SUFFIX,pythonhosted.org,Proxy # 3. AI服务 DOMAIN-KEYWORD,anthropic,Proxy DOMAIN-KEYWORD,openai,Proxy DOMAIN-KEYWORD,openrouter,Proxy DOMAIN-KEYWORD,cloudflare,Proxy # 4. 其他海外服务 DOMAIN-SUFFIX,google.com,Proxy DOMAIN-SUFFIX,stackoverflow.com,Proxy DOMAIN-SUFFIX,stackoverflow.co,Proxy # 5. 兜底 MATCH,DIRECT

订阅内置规则 vs 自定义规则

方式优点缺点
使用订阅内置规则简单，机场提供可能不包含最新域名
自定义规则灵活，按需配置需要手动维护
混合模式最佳平衡配置稍复杂
推荐 混合模式配置

步骤：

1. 订阅配置 → 关闭"覆盖规则"（保留订阅的内置规则）

2. 在订阅配置底部添加"额外规则"

3. 将自定义规则添加进去

这样订阅更新时不会覆盖你的自定义规则。

五、开发场景

OPC开发必备配置

场景一：npm/yarn/pnpm 加速

# 设置npm镜像（适合不需要代理的场景） npm config set registry https://registry.npmmirror.com # 如果npm安装特定包需要从GitHub下载源码 # 确保git可以访问github.com git config --global url."https://github.com/".insteadOf git://github.com/ # 如果遇到私有包需要SSH eval "$(ssh-agent -s)" ssh-add ~/.ssh/id_rsa

场景二：Claude Code / Cursor 网络配置

# 让AI工具使用系统代理 # 确保Clash开启"系统代理"模式 # 或者设置环境变量 export https_proxy=http://127.0.0.1:7890 export http_proxy=http://127.0.0.1:7890 export all_proxy=socks5://127.0.0.1:7890 # Windows PowerShell $env:HTTPS_PROXY = "http://127.0.0.1:7890" $env:HTTP_PROXY = "http://127.0.0.1:7890"

场景三：Git 加速

# GitHub 加速 # 方法1：使用镜像站 git clone https://hub.fastgit.xyz/owner/repo.git # 方法2：修改hosts文件 # 添加到 /etc/hosts (macOS/Linux) 或 C:\Windows\System32\drivers\etc\hosts 140.82.121.4 github.com 199.232.69.194 github.global.ssl.fastly.net # 方法3：通过代理 git config --global http.proxy http://127.0.0.1:7890 git config --global https.proxy http://127.0.0.1:7890 # 取消代理 git config --global --unset http.proxy git config --global --unset https.proxy

场景四：应用级代理（Proxifier）

有些应用不支持系统代理，需要使用Proxifier进行应用级代理。

# Proxifier 配置 # 1. Profile → Proxy Servers → 添加 # Address: 127.0.0.1 # Port: 7890 (Clash HTTP代理端口) # Protocol: SOCKS5 (或HTTP，根据Clash配置) # 2. Profile → Proxification Rules → 添加规则 # 应用程序：选择需要代理的应用 # 动作：指向Clash代理服务器

场景五：终端代理（proxychains）

# macOS 安装 proxychains-ng brew install proxychains-ng # 配置 /usr/local/etc/proxychains.conf # 在 [ProxyList] 下添加 socks5 127.0.0.1 7890 # 使用 proxychains4 curl https://api.anthropic.com proxychains4 git clone https://github.com/xxx/xxx.git
六、常见问题

FAQ

Q: 订阅链接打不开怎么办？

A: 首先确认链接是否正确。可能是订阅过期或欠费。尝试在浏览器中打开订阅链接，如果显示乱码说明链接正确，如果显示"需要登录"说明链接已失效。

Q: 节点速度很慢怎么办？

A: 切换到其他节点测试。不同节点在不同地区有不同速度。优先选择延迟低（< 150ms）的节点。如果所有节点都慢，可能是机场带宽不足，考虑换一家。

Q: 如何测试速度？

A: 在Clash Verge中，右键节点 → "延迟测试"。也可以直接访问 speedtest.net 测试实际带宽。

Q: 订阅需要多久更新一次？

A: 通常建议每天自动更新一次（Clash Verge可配置）。节点IP可能会变化，不更新会导致连接失败。

Q: 如何让特定应用走代理？

A: 方案1：使用Proxifier（应用级代理）。方案2：Clash Verge的"增强模式"可以按应用分流。方案3：终端中使用proxychains。

Q: 工作正常但突然断了？

A: 常见原因：1）节点被封（切换节点）；2）订阅过期（续费）；3）流量用完（检查用量）；4）当地网络波动（等恢复）。

Q: 国内需要访问的服务走不了？

A: 在规则中添加对应域名即可。例如微信相关服务走DIRECT（国内直连），不要添加代理规则。

快速开始 Checklist

  • 下载安装 Clash Verge
  • 获取机场订阅链接
  • 在Clash中添加并更新订阅
  • 测试节点延迟，选择优质节点
  • 配置分流规则（参考推荐规则）
  • 设置系统代理为Clash
  • 测试访问 github.com 和 npmjs.com

记住：Clash是OPC的"网络基础设施"。稳定、规则合理的Clash配置，能让你的开发效率提升50%以上。

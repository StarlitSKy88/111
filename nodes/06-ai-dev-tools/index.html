06 / 开发工具

AI开发工具集

OPC节点百科配套教程。覆盖AI编码工具、模型平台、云服务、网络工具等开发全流程所需的工具配置与使用指南。

优先级说明：P0 = 立即配置，P1 = 近期配置，P2/P3 = 按需配置
本章速读
  • 目标：在动笔写第一行代码前，就把 OPC 开发的"兵器谱"配齐：1 个 AI 编码代理 + 1 个模型路由 + 1 套云基础设施。
  • 你要做的事：3 步：① 装 Claude Code / Cursor 作为主代理 → ② 接 OpenRouter 做模型路由 → ③ 部署 Vercel + Supabase 跑通 Hello World。
  • 不需要会：不需要全栈 20 个工具都装（先 P0 三件套），不需要买付费云（个人免费档够用 1 年），不需要懂 Docker（云厂商已封装）。
  • 本章产出：1 张《P0/P1/P2 工具优先级表》+ 1 份《个人环境配置 Checklist》+ 1 份《工具替代方案对照表》（如无海外卡）。

工具配置顺序

  • 第一步：Clash（解决网络问题，才能访问海外服务）
  • 第二步：OpenRouter（获取AI模型API，统一管理）
  • 第三步：Claude Code（开始AI辅助编程）
  • 第四步：腾讯云（购买域名、服务器、ICP备案）
  • 第五步：Cursor/GitHub/Supabase（日常开发工具链）
  • 第六步：Vercel/Docker（部署与容器化）
  • 第七步：支付/统计/邮件（生产环境配套）

记住：工具是OPC的"团队"。配置好基础设施，才能高效开发。

06 / 支付工具

Stripe

全球领先的在线支付网关。支持信用卡、借记卡 ACH 转账等135+种货币支付。为独立开发者提供最完善的支付基础设施和开发者体验。

最后修订：2026年5月14日 · 官方文档：stripe.com/docs
一、核心定位

Stripe是什么

Stripe成立于2010年，是专为软件公司和独立开发者设计的在线支付平台。与传统支付网关不同，Stripe提供一套完整的API，让你可以收款、管理订阅、处理退款、处理欺诈。

核心竞争力

开发者优先：业界最完善的API设计、SDK覆盖10+语言、详细的文档和示例代码。

全球化收款：支持135+种货币，覆盖美国、欧盟、英国、加拿大等40+个国家/地区。

一站式解决方案：不只是收款，还提供订阅管理、发票系统、Radar反欺诈、Connect marketplaces等功能。

Stripe vs 国内支付

对比维度Stripe微信支付支付宝
目标市场全球（尤其欧美）中国大陆中国大陆
主要货币135+种CNYCNY
结算周期2天（标准）T+1T+1
API体验业界最佳一般一般
适合客户出海OPC、海外用户国内客户国内客户
开户要求海外公司/个人大陆公司/个体户大陆公司/个体户

什么时候用Stripe：

你的目标用户在海外（如美国、欧洲、东南亚），或者你想做SaaS订阅、在线课程、数字产品销售等需要国际信用卡支付的场景，Stripe是首选。

二、账户注册

快速上手

注册条件

  • 支持个人账户（香港、美国等）或公司账户
  • 需要有效的邮箱和手机号
  • 香港账户支持全球收款，但提现需要香港银行卡
  • 美国账户需要ITIN或SSN

注册步骤

# 1. 访问 Stripe 官网注册 https://dashboard.stripe.com/register # 2. 填写基本信息 # - 邮箱地址（将成为登录账号） # - 姓名（真实姓名，用于验证） # - 国家/地区（影响账户类型和支持功能） # 3. 邮箱验证 # 登录邮箱，点击验证链接 # 4. 完成身份验证 # - 上传身份证件（护照、驾照等） # - 可能需要补充地址证明

获取API密钥

注册完成后，在Dashboard中获取API密钥用于开发。

# 1. 登录 Stripe Dashboard https://dashboard.stripe.com # 2. 导航到 Developers > API Keys # 3. 复制密钥 # - Publishable Key（前端使用，pk_开头） # - Secret Key（后端使用，sk_开头） # 注意：测试密钥和正式密钥不同 # - 测试密钥：sk_test_xxxxx（不会产生真实交易） # - 正式密钥：sk_live_xxxxx（产生真实交易）

测试模式 vs 正式模式

Stripe默认提供两套密钥：测试（Test）和正式（Live）。开发阶段使用测试密钥，所有交易都是模拟的，不会真实扣款。上线前切换到正式密钥。

安装SDK

# Node.js npm install stripe # Python pip install stripe # 前端（Stripe.js） <script src="https://js.stripe.com/v3/"></script>
三、核心概念

核心对象模型

Payment Intent（支付意图）

Payment Intent是Stripe的核心概念，代表一次支付的全部信息：金额、货币、支付方式、状态。它经历创建→确认→完成/失败的生命周期。

创建 Payment Intent
→
前端使用 Payment Intent Client Secret 确认支付
→
Stripe 处理支付
→
Webhook 通知结果

Customer（客户）

Customer对象存储客户信息，便于后续订阅管理和历史查询。创建Payment Intent时可以关联客户，也可以匿名支付。

# 创建客户 const customer = await stripe.customers.create({ email: 'customer@example.com', name: '张三', metadata: { user_id: '12345' } }); # 创建后返回客户ID：cus_xxxxx

Charge（扣款）

Charge是成功完成的支付。当Payment Intent确认后，Stripe会创建一个Charge。Charge包含所有交易细节：卡信息、金额、状态、创建时间。

Subscription（订阅）

Subscription用于周期性的收费场景（如月费、年费）。Stripe会自动处理订阅的周期计算、扣款、续期、取消。

# 创建订阅 const subscription = await stripe.subscriptions.create({ customer: 'cus_xxxxx', items: [{ price: 'price_xxxxx', // 定价ID，从Dashboard创建 }], payment_behavior: 'default_incomplete', payment_settings: { save_default_payment_method: 'on_subscription' }, expand: ['latest_invoice.payment_intent'], });

Price（定价）

Price定义了你的产品/服务的定价。可以是固定金额或按量计费，支持多种货币和周期。

定价周期说明适用场景
一次性单次付款课程、工具、软件
每天每天扣费不常见
每周每周扣费新闻订阅、内容会员
每月每月扣费SaaS、会员
每年每年扣费SaaS、会员（通常有折扣）
四、集成方式

支付集成方案

方案一：Stripe Checkout（托管页）

Stripe Checkout是Stripe提供的托管支付页面。你只需创建一个Session，用户就会被跳转到Stripe的支付页面完成付款。这是最简单的方式，适合快速集成。

# 后端：创建Checkout Session const session = await stripe.checkout.sessions.create({ mode: 'payment', payment_method_types: ['card'], line_items: [{ price_data: { currency: 'usd', product_data: { name: '产品名称', description: '产品描述', }, unit_amount: 2999, // $29.99（单位：分） }, quantity: 1, }], success_url: 'https://yourdomain.com/success', cancel_url: 'https://yourdomain.com/cancel', }); # 返回 session.id，前端跳转 res.redirect(session.url);
# 前端：跳转到Checkout <button id="checkout-button">立即购买</button> <script> const stripe = Stripe('pk_test_xxxxx'); document.getElementById('checkout-button') .addEventListener('click', async () => { const { error } = await stripe.redirectToCheckout({ sessionId: '<%= session.id %>', }); }); </script>

方案二：Stripe Elements（嵌入式）

Stripe Elements是嵌入式组件，让用户在你的网站内完成支付，无需跳转。适合需要保持品牌一致性的场景。

# 前端：嵌入Stripe Elements <form id="payment-form"> <div id="payment-element"></div> <button type="submit">支付 $29.99</button> </form> <script> const stripe = Stripe('pk_test_xxxxx'); const elements = stripe.elements({ clientSecret: '<%= clientSecret %>', // 从后端获取 }); const paymentElement = elements.create('payment'); paymentElement.mount('#payment-element'); // 提交支付 form.addEventListener('submit', async (e) => { e.preventDefault(); const { error } = await stripe.confirmPayment({ elements, confirmParams: { return_url: 'https://yourdomain.com/success', }, }); }); </script>

方案三：API直接集成

对于复杂场景，可以直接使用Stripe API创建Payment Intent并在后端处理。

# 后端：创建Payment Intent const paymentIntent = await stripe.paymentIntents.create({ amount: 2999, // 金额（分） currency: 'usd', payment_method_types: ['card'], metadata: { order_id: 'order_12345', }, }); # 返回 client_secret，前端用于确认支付 res.json({ clientSecret: paymentIntent.client_secret, });

OPC建议：初创阶段使用Stripe Checkout最省事。随着业务复杂化，迁移到Stripe Elements或API直接集成。

六、Webhooks

支付事件通知

Webhook允许Stripe在支付状态变化时主动通知你的服务器。这对于确认支付成功、更新订单状态、触发后续流程至关重要。

配置Webhook

# 1. 在Dashboard配置端点 # Stripe Dashboard > Developers > Webhooks # 添加 endpoint：https://yourdomain.com/api/webhook # 2. 选择监听的事件 # - payment_intent.succeeded（支付成功） # - payment_intent.payment_failed（支付失败） # - customer.subscription.created（订阅创建） # - invoice.payment_succeeded（发票支付成功）

处理Webhook

# Node.js / Express 处理Webhook const express = require('express'); const app = express(); app.post('/api/webhook', express.raw({type: 'application/json'}), async (req, res) => { const sig = req.headers['stripe-signature']; const endpointSecret = 'whsec_xxxxx'; // Webhook签名密钥 let event; try { event = stripe.webhooks.constructEvent(req.body, sig, endpointSecret); } catch (err) { return res.status(400).send(`Webhook Error: ${err.message}`); } // 处理不同事件 switch (event.type) { case 'payment_intent.succeeded': const paymentIntent = event.data.object; console.log('支付成功:', paymentIntent.id); // TODO: 更新订单状态、发送确认邮件等 break; case 'payment_intent.payment_failed': const failedIntent = event.data.object; console.log('支付失败:', failedIntent.id); break; case 'customer.subscription.created': const subscription = event.data.object; console.log('订阅创建:', subscription.id); break; } res.json({received: true}); });

Webhook安全

必须验证Webhook签名防止伪造。使用stripe.webhooks.constructEvent()验证请求真实性。不要直接信任请求body。

本地测试Webhooks

# 使用Stripe CLI监听并转发Webhook到本地 stripe listen --forward-to localhost:3000/api/webhook # 会输出 webhook signing secret，类似： # whsec_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx # 触发测试事件 stripe trigger payment_intent.succeeded

八、常见问题

FAQ

Q: Stripe支持哪些国家？

A: Stripe支持40+个国家/地区，包括美国、加拿大、英国、德国、法国、日本、澳大利亚、新加坡、香港等。具体列表见官方文档。中国大陆目前不支持，但可以注册香港账户。

Q: 资金多久到账？

A: 标准结算周期是2天。资金会转入你绑定的银行账户。对于新账户或高风险交易，Stripe可能会延迟结算（最多14天）。

Q: 如何避免欺诈交易？

A: 使用Stripe Radar，它是内置的机器学习反欺诈系统。根据风险等级自动标记或阻止可疑交易。基础版免费，高级版每笔$0.05-$0.07。

Q: 可以退款吗？

A: 可以。通过Dashboard或API发起退款。退款处理费不退，其他费用全额返还。退款必须在180天内发起。

Q: 如何处理支付失败？

A: 通过Webhook监听payment_intent.payment_failed事件。常见失败原因：卡余额不足、卡过期、CVV验证失败。根据错误信息引导用户更换支付方式。

Q: Stripe适合什么类型的业务？

A: 数字产品销售、在线课程、SaaS订阅、服务收费、众筹捐款等需要国际信用卡支付的场景。如果只服务国内用户，微信/支付宝更合适。

Q: 香港账户和美国账户怎么选？

A: 香港账户：支持多货币，结算较快，但需要香港银行卡收人民币。美国账户：美元结算优势大，但需要ITIN或SSN。建议香港账户起步。

Q: 是否有月费或设置费？

A: 无月费、无设置费、无年费。只有交易手续费（2.9%+$0.30）。只有当你需要定制定价（交易量大）或使用Stripe Atlas（公司注册）时才可能有额外费用。

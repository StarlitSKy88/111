06 / 开发工具

Resend

现代事务性邮件API，为开发者打造。支持 React Email 组件化构建精美邮件，3000封/月免费额度。

分类：通讯服务 · 优先级：P1（重要）
01 · 核心定位

什么是 Resend

Resend 是一家专注于开发者体验的事务性邮件服务商，由 AngularJS 创始人 Miško Hevery 创立于2023年。它的核心理念是让邮件发送变得像发送 API 请求一样简单。

Resend vs 传统邮件服务

传统邮件服务（如 SendGrid、Mailgun）的 API 设计往往陈旧，文档混乱。Resend 提供了现代化的 API 和 React Email 组件库，让邮件开发回归开发者熟悉的编程模式。

核心优势

  • 现代化的 REST API，几分钟完成集成
  • React Email 组件库，用 React 构建精美邮件
  • 内置邮箱身份验证（DKIM、SPF、DMARC）
  • 实时邮件分析（送达、打开、点击）
  • 免费额度大（3000封/月）
  • 支持自定义域名邮箱（如 hello@yourdomain.com）

适用场景

Resend 特别适合以下场景：

场景 说明
用户注册/登录 欢迎邮件、邮箱验证、密码重置
订单通知 订单确认、发货通知、快递追踪
产品更新 新功能公告、版本发布说明
营销邮件 促销活动、用户召回、Newsletter
系统通知 账单到期、服务异常、账户安全
02 · 快速上手

开始使用 Resend

Resend 的上手流程非常简洁，整个过程约15分钟即可完成。

第一步：创建账户

访问 resend.com，使用 GitHub 或 Google 账号登录。免费账户无需绑定信用卡。

第二步：验证域名

在 Dashboard 中添加你的发送域名（如 yourdomain.com）。Resend 会生成 DNS 记录，你需要在域名服务商处添加这些记录。

# 添加 DKIM 记录（提升邮件可信度） Host: mail._domainkey.yourdomain.com Type: TXT Value: "v=DKIM1; k=rsa; p=你的公钥" # 添加 SPF 记录（允许 Resend 代表你发送邮件） Host: yourdomain.com Type: TXT Value: "v=spf1 include:resend.com ~all" # 添加 DMARC 记录（防止邮件伪造） Host: _dmarc.yourdomain.com Type: TXT Value: "v=DMARC1; p=quarantine; rua=mailto:dmarc@yourdomain.com"

第三步：获取 API Key

在 Dashboard → API Keys 中创建新的 API Key。妥善保存，不要泄露到前端代码中。

# 环境变量配置（后端） RESEND_API_KEY=re_xxxxxxxxxxxxx # 安装 SDK npm install resend

第四步：发送第一封邮件

import { Resend } from 'resend'; const resend = new Resend('re_xxxxxxxxxxxxx'); const { data, error } = await resend.emails.send({ from: 'yourdomain.com', to: 'recipient@example.com', subject: 'Hello from Resend', html: '

This is a test email sent with Resend.

' }); if (error) { console.error('Error:', error); }

域名验证状态

DNS 记录添加后，通常需要 5-30 分钟生效。Resend Dashboard 会显示域名验证状态。验证通过前，只能向已验证的邮箱地址发送测试邮件。

03 · 核心概念

Resend 核心概念

Resend 的数据模型围绕四个核心实体展开，理解它们是深度使用的基础。

Emails（邮件）

Email 是发送的基本单元。每次调用发送接口就会创建一个 Email 记录。Email 包含以下属性：

属性 说明
from 发件人地址，格式为 name@yourdomain.com
to 收件人地址，支持多个（用逗号分隔）
subject 邮件主题
html / text 邮件内容（二选一）
cc / bcc 抄送/密送（可选）
attachments 附件（可选）
headers 自定义邮件头

Contacts（联系人）

Contact 是邮件收件人的基本信息库。你可以直接通过 API 批量导入联系人，也可以让 Resend 自动从发送记录中创建。

// 批量创建联系人 const contacts = await resend.contacts.create({ audienceId: 'aud_xxxxx', email: 'user@example.com', firstName: '张', lastName: '三', unsubscribed: false });

Audiences（受众群体）

Audience 是联系人的分组，便于分类发送和管理。例如：

  • 免费用户群体
  • 付费用户群体
  • 最近30天活跃用户
  • 已退订用户（隔离）
// 创建受众群体 const audience = await resend.audiences.create({ name: '付费用户', description: '已完成付费的用户' });

Campaigns（营销活动）

Campaign 是面向特定受众群体的批量邮件发送。你可以：

  • 设置发送时间（定时发送）
  • 追踪打开率、点击率
  • A/B 测试不同主题
  • 管理退订链接

06 · DNS配置

DNS 身份验证设置

正确配置 DNS 记录是确保邮件送达率的关键。邮件服务商根据这些记录判断邮件是否来自合法发送者。

为什么需要 DNS 配置

  • 防止伪造 — 黑客无法假装你的域名发送邮件
  • 提升送达率 — 主流邮件服务商（Gmail、Outlook）要求 SPF/DKIM
  • 避免垃圾箱 — 未认证的邮件容易被标记为垃圾邮件
  • 品牌保护 — 防止他人冒用你的域名

必需记录

SPF 记录

声明哪些服务器被授权发送你的域名邮件

在域名服务商添加 TXT 记录：

主机名: yourdomain.com 类型: TXT 值: v=spf1 include:resend.com ~all # 说明： # v=spf1 — 这是 SPF 记录 # include:resend.com — 授权 Resend 的服务器发送 # ~all — 如果邮件来自未授权服务器，标记为软失败（建议） # -all — 严格模式，任何未授权来源直接拒绝

DKIM 记录

公钥加密签名，验证邮件内容未被篡改

Resend Dashboard 会提供 DKIM 公钥，添加方式：

主机名: mail._domainkey.yourdomain.com 类型: TXT 值: v=DKIM1; k=rsa; p=你的公钥内容... # 说明： # mail._domainkey — DKIM 标准选择器 # k=rsa — 使用 RSA 加密算法 # p= — 后跟 Resend 提供的公钥

DMARC 记录

告诉邮件服务商如何处理未通过验证的邮件

建议从宽松策略开始，逐步严格：

主机名: _dmarc.yourdomain.com 类型: TXT 值: v=DMARC1; p=quarantine; rua=mailto:dmarc@yourdomain.com # 说明： # v=DMARC1 — 版本标识 # p=quarantine — 发现问题邮件送入垃圾箱（推荐起始值） # p=reject — 严格模式，直接拒绝 # rua= — 汇总报告发送地址

验证配置

配置完成后，可以使用以下工具验证：

  • Resend Dashboard → Domains → 点击 "Verify" 按钮
  • MXToolbox — https://mxtoolbox.com/
  • DMARC Inspector — https://dmarcinspector.com/

生效时间

DNS 记录修改后，全球传播可能需要 5 分钟到 48 小时。通常在 30 分钟内生效，完整扩散需要 24-48 小时。

07 · React Email

用 React 构建精美邮件

React Email 是 Resend 官方开源的邮件组件库，让你用熟悉的 React 语法构建跨邮件客户端的精美模板。

为什么用 React Email

  • 不再拼接字符串模板，用组件化思维构建邮件
  • 预置精美组件（Button、Card、Image、Grid 等）
  • 自动适配 40+ 邮件客户端（Outlook、Gmail、Apple Mail 等）
  • 支持 TypeScript，类型安全
  • 代码即文档，可维护性高

核心组件

import { Html, Head, Body, Container, Section, Row, Column, Text, Button, Link, Image, Hr, Pre, Code } from '@react-email/components'; // 完整示例 export function OrderConfirmationEmail({ order }) { return (
订单确认
感谢你的订单！订单号：{order.id}
{order.items.map(item => ( {item.name} x {item.quantity} ¥{item.price} ))}
总计：¥{order.total}
); }

样式最佳实践

  • 使用内联样式（React Email 不支持外部 CSS）
  • 布局使用 Table 而非 Flexbox（邮件客户端兼容性）
  • 图片务必指定 width 和 height
  • 字体大小不小于 14px
  • 按钮至少 44px 高，方便点击
  • 留白使用 padding 而非 margin

09 · 常见问题

FAQ

Resend 免费额度用完后会怎样？

免费额度（3000封/月）用完后，API 会返回错误。建议在接近限额前升级套餐或购买额外额度。你可以在 Dashboard 设置用量提醒。

如何提升邮件送达率？

  • 完成域名 DNS 验证（SPF、DKIM、DMARC）
  • 保持低退订率（发送用户愿意接收的邮件）
  • 避免垃圾邮件关键词（免费、优惠、立即等）
  • 定期清理无效邮箱地址
  • 发送频率稳定，不要突然大量发送

Resend 支持国内邮件服务吗？

Resend 是海外服务，对国内邮箱（QQ、163、企业邮箱）的投递相对稳定，但如果主要用户是国内市场，建议使用国内邮件服务（如 SendGrid 中国版、阿里云邮件推送）作为备选。

可以发送附件吗？

可以。通过 attachments 参数添加，附件大小限制为 20MB。大型文件建议使用对象存储，将下载链接放在邮件中。

如何追踪邮件是否被打开？

Resend 自动追踪送达、打开、点击数据。你可以在 Dashboard 查看详细统计，或通过 Webhook 获取实时事件通知。

支持定时发送吗？

支持。Campaign 模式支持设置定时发送（scheduledTime 参数）。定时精度为分钟级别。

React Email 可以单独使用吗？

可以。React Email 是独立开源项目，可以与任何邮件服务配合使用（SendGrid、Postmark、Mailgun 等），不强制依赖 Resend。

如何处理退订？

所有营销邮件必须包含退订链接。使用 Resend 的 Audiences 功能可以自动管理退订用户，确保合规。

关键要点

  • Resend 是现代化事务性邮件 API，适合开发者使用
  • 免费额度 3000 封/月，足够 OPC 早期阶段
  • React Email 是核心优势，用 React 构建精美邮件
  • DNS 配置（SPF/DKIM/DMARC）是确保送达率的关键
  • 遵循最佳实践：清晰的退订链接、避免垃圾词、控制发送频率

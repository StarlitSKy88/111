06 / AI开发工具

OpenRouter

AI模型的聚合平台，一站式访问100+大模型API。支持Claude、GPT-4o、Gemini、国产模型（DeepSeek、Qwen等）。统一接口，按量计费。

最后修订：2026年5月14日 · 官方：openrouter.ai
一、核心定位

为什么需要OpenRouter

2026年AI模型市场碎片化严重。OpenAI、Anthropic、Google、国内阿里百度字节……每个平台有自己的API、定价、限流规则。OPC如果需要切换模型，逐一对接每个平台会消耗大量时间。

OpenRouter的核心价值

统一接口：无论接入多少模型，API格式完全一致。一个base URL + 一个key，切换模型只需改参数。

模型聚合：100+模型，包括Claude 3.7、GPT-4o、Gemini 2.0、DeepSeek V3、Qwen 2.5等。

透明定价：明码标价，平台不赚差价（官方价格+少量服务费）。

路由优化：自动选择性价比最高的模型，支持"用最便宜模型达到同样效果"的策略。

OpenRouter vs 直连官方

对比维度OpenRouter直连官方
模型数量100+1个平台
API格式统一（OpenAI兼容）各平台独立
切换成本改参数即可需要改代码
价格官方价+5-10%服务费官方价
稳定性多区域备份依赖单平台
开票支持支持

什么时候用OpenRouter：需要灵活切换模型、对比不同模型效果、同时使用国内外模型的OPC。单一模型深度使用直接找官方（更便宜）。

三、接入配置

快速开始

注册与充值

  • 访问 openrouter.ai，使用Google/GitHub账号登录
  • 进入Credit购买页面，支持支付宝
  • 最小充值$5，建议首次充值$20测试
  • 获取API Key（个人设置 → API Keys）

API Key配置

# 环境变量配置 export OPENROUTER_API_KEY=sk-or-v1-xxxxx # 如果代码需要OpenAI兼容格式 export OPENAI_API_KEY=$OPENROUTER_API_KEY export OPENAI_API_BASE=https://openrouter.ai/api/v1

模型列表查询

# 查看所有可用模型 curl https://openrouter.ai/api/v1/models \ -H "Authorization: Bearer $OPENROUTER_API_KEY" # 返回JSON包含所有模型ID、定价、上下文长度

SDK接入

# Node.js (使用 OpenAI SDK) npm install openai # JavaScript const OpenAI = require('openai'); const client = new OpenAI({ apiKey: process.env.OPENROUTER_API_KEY, baseURL: 'https://openrouter.ai/api/v1' }); // 调用Claude const response = await client.chat.completions.create({ model: 'anthropic/claude-3.7-sonnet', messages: [{ role: 'user', content: 'Hello' }] }); // 切换到DeepSeek（只需改model参数） const response2 = await client.chat.completions.create({ model: 'deepseek/deepseek-chat-v3-0324', messages: [{ role: 'user', content: '你好' }] });

Python接入

pip install openai # Python from openai import OpenAI client = OpenAI( api_key=os.getenv("OPENROUTER_API_KEY"), base_url="https://openrouter.ai/api/v1" ) response = client.chat.completions.create( model="deepseek/deepseek-chat-v3-0324", messages=[{"role": "user", "content": "用Python写一个快速排序"}] ) print(response.choices[0].message.content)

成本优化策略

策略一：模型分级

简单任务（闲聊、格式转换）→ DeepSeek/Qwen（$0.15/M）

中等任务（代码补全、翻译）→ GPT-4o-mini（$0.15/M）

复杂任务（复杂推理、重构）→ Claude 3.7（$3.50/M）

策略二：使用路由

OpenRouter提供自动路由功能，让平台自动选择"最便宜的能达到同等效果的模型"。

配置方式：在model参数填入openrouter/auto

用量监控

# 查看当前账户余额和用量 curl https://openrouter.ai/api/v1/auth/key \ -H "Authorization: Bearer $OPENROUTER_API_KEY" # 返回示例 { "data": { "id": "sk-or-v1-xxxxx", "label": "default", "usage": 123456789, "limit": null, "created_at": "2024-01-01T00:00:00Z" } } # usage单位是nanodollar，$1 = 1,000,000,000 # 当前用量 = 123456789 / 1e9 = $0.123

五、API使用

进阶功能

指定模型参数

# 完整参数示例 const response = await client.chat.completions.create({ model: 'anthropic/claude-3.7-sonnet', messages: [ { role: 'system', content: '你是一个专业的产品经理' }, { role: 'user', content: '帮我写一个用户注册的功能需求' } ], temperature: 0.7, // 创造性 0-2 max_tokens: 2000, // 最大输出token top_p: 1, // 核采样 frequency_penalty: 0, // 频率惩罚 presence_penalty: 0, // 存在惩罚 stop: null, // 停止词 });

使用Prompt模板

# OpenRouter支持自定义Prompt模板（社区功能） # 格式：owner/prompt-name const response = await client.chat.completions.create({ model: 'anthropic/claude-3.7-sonnet', messages: [{ role: 'user', content: '写一个注册功能' }], extra_body: { prompt: { template: '你是一个经验丰富的后端工程师，擅长{language}，遵循{style}风格' } } });

获取使用统计

# 查看每日用量 curl 'https://openrouter.ai/api/v1/usage' \ -H "Authorization: Bearer $OPENROUTER_API_KEY" # 返回 { "data": [ { "date": "2026-05-14", "total_cost": 1234567, "requests": 156, "tokens": { "input": 123456, "output": 78901 } } ] }

八、常见问题

FAQ

Q: OpenRouter安全吗？API Key会不会被盗用？

A: OpenRouter是正规平台，采用与官方相同的安全标准。建议：只在服务端使用API Key（不要暴露在前端）、定期更换Key、在平台设置用量限制（Limit）。

Q: 为什么通过OpenRouter比官方贵？

A: OpenRouter收取5-17%的服务费，用于覆盖信用卡手续费、多区域服务器成本、客户支持等。对于需要切换多模型的项目，这个溢价是值得的。

Q: 国内访问OpenRouter稳定吗？

A: OpenRouter服务器主要在海外，国内访问不稳定。但其聚合的国产模型（DeepSeek、Qwen）可以通过国内节点访问。建议国内OPC使用VPN。

Q: 如何设置用量限制防止超支？

A: 在OpenRouter Dashboard → API Keys → 设置limit（单位：美元/月）。当月用量达到限制后，API会返回错误。

Q: 充值后多久到账？

A: 支付宝/微信支付通常秒到账。信用卡可能需要1-2分钟。

Q: 可以开票报销吗？

A: OpenRouter支持企业发票（Invoice），可在Dashboard申请。发票抬头必须是公司名称。

Q: DeepSeek和Qwen用哪个？

A: DeepSeek在代码和数学推理上更强；Qwen在中文内容创作上更自然。OPC建议：开发相关用DeepSeek，内容相关用Qwen。

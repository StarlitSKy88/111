核心定位

为什么OPC用Vercel？

Vercel是一个专注于前端应用的部署平台，最出名的是支持Next.js、React等框架的无缝部署。它的核心理念是：你只管写代码，部署、SSL、CDN、预览环境全部自动化。

维度Vercel传统方式（云服务器）
部署方式git push 自动触发手动上传或CI配置
运维工作零运维，平台包揽需自己管理服务器、Nginx、防火墙
SSL证书自动配置，自动续期手动申请Let's Encrypt
预览环境每个PR自动生成预览链接需手动配置
费用个人项目免费云服务器月费24元起
备案无需备案（海外节点）国内服务器必须备案

最适合的场景

  • 前端项目（React/Vue/Next.js）
  • 静态网站生成器（Hexo/Hugo）
  • 不想碰服务器运维的OPC
  • 需要快速验证MVP的阶段
  • 有海外用户的产品（香港/日本节点）

Vercel = 不用管理的服务器。你Push代码，它自动部署、自动SSL、自动CDN。OPC可以把全部精力放在产品上，而不是运维上。

快速上手

三步完成第一个部署

1

安装Vercel CLI

在终端运行以下命令，需要Node.js环境（建议18.x以上）

npm i -g vercel
2

登录Vercel账号

推荐使用GitHub账号登录打通了GitHub和部署流程。

vercel login
3

在项目目录执行部署

进入你的项目目录，运行vercel，按提示选择配置即可。

cd your-project vercel

部署过程中会询问：

  • 是否链接到现有项目（选是）
  • 构建命令是什么（Next.js默认next build）
  • 输出目录是什么（静态网站填.）

部署完成后，你会得到一个.vercel.app结尾的域名，这就是你的线上地址。整个过程不超过3分钟。

核心功能

这些功能全部免费

自动HTTPS

SSL证书自动申请、自动配置、自动续期。你什么都不用管，浏览器永远显示安全锁。

预览部署

每次GitHub PR会自动生成一个预览链接，审核者可以直接点开看效果。合并后自动上线。

边缘网络

全球CDN节点，访问时自动路由到最近节点。海外用户访问速度比国内服务器更快。

实时日志

每个部署版本都有完整的构建日志和运行时日志，出错时可以直接看到是哪一步失败。

回滚功能

一键回滚到任何一个历史版本。线上出问题不用慌，三秒回到上一个稳定版本。

环境变量

在Dashboard配置环境变量，部署时自动注入。API密钥不用写在代码里。

Vercel Functions（边缘函数）

不需要单独购买服务器，在Vercel上可以直接写API接口。使用方式极其简单：

// api/hello.js export default function handler(req, res) { res.status(200).json({ message: 'Hello OPC' }) }

这个文件会自动部署为一个Serverless函数，可以通过/api/hello访问。免费版每月100GB带宽，足够个人项目使用。

自定义域名

绑定自己的域名

第一步：在Vercel添加域名

  1. 进入 Vercel Dashboard
  2. 选择你的项目 → Settings → Domains
  3. 输入你的域名（如 yourdomain.com）
  4. 点击 Add

第二步：配置DNS记录

去你的域名服务商（阿里云/腾讯云/Cloudflare）添加以下DNS记录：

# CNAME记录（最常用） # 将 www.yourdomain.com 指向 cname.vercel-dns.com www CNAME cname.vercel-dns.com # 或者A记录（如果不需要www） @ A 76.76.21.21

第三步：等待验证

DNS配置后，Vercel会自动验证域名所有权。验证通过后：

  • SSL证书自动申请并配置
  • HTTP自动跳转到HTTPS
  • 全球CDN自动开启

整个过程不需要你手动申请SSL证书，不需要配置Nginx，不需要操作任何服务器。Vercel全部自动化完成。

国内域名注意事项

如果你使用国内域名（.cn结尾），Vercel的DNS可能解析较慢。建议同时配置一个境外解析，或者使用Cloudflare作为DNS代理，然后在Vercel绑定域名。

实战案例

从GitHub到上线的完整流程

案例：部署一个React静态网站

1

在GitHub创建仓库

把项目代码推送到GitHub。Vercel通过GitHub触发部署。

git init git add . git commit -m "first commit" git branch -M main git remote add origin https://github.com/yourname/yourproject.git git push -u origin main
2

在Vercel导入项目

Dashboard → Add New → Project → Import from GitHub

3

配置构建命令

Vercel会自动检测框架。如果检测不到，手动配置：

# React + Vite 项目 Build Command: npm run build Output Directory: dist
4

配置环境变量（可选）

如果项目需要API密钥，在Environment Variables中添加。

5

点击Deploy

完成！Vercel会自动构建并部署，每次Git push都会自动触发新部署。

配置CI/CD自动化

Vercel和GitHub深度集成，天然支持CI/CD：

  • Push代码 → 自动触发构建
  • 创建PR → 自动生成预览链接
  • 合并PR → 自动部署到生产
  • 构建失败 → 通知GitHub并阻止合并
# .github/workflows/deploy.yml（可选） # Vercel自动部署，无需额外配置CI
常见问题

FAQ

Vercel在国内访问速度怎么样？

Vercel在海外有大量节点（日本、韩国、香港、新加坡），国内访问速度中等。如果你的用户主要在国内，可以考虑使用腾讯云或阿里云。但如果你的产品有海外用户，Vercel的边缘网络会让海外访问体验很好。

免费版有时间和流量限制吗？

有。Hobby版每月100GB带宽和100小时服务器时间。个人项目一般不会超过这个限制。如果超了，当月服务会暂停，下个月恢复。不会突然扣费。

Vercel能绑定国内域名吗？

可以绑定，但国内域名需要备案才能正常解析。如果你的域名要用于国内业务，需要先完成ICP备案，然后DNS指向Vercel即可。备案是工信部的要求，和Vercel无关。

Vercel能访问数据库吗？

可以。Vercel只是部署平台，你的数据库可以放在任何地方：Supabase、PlanetScale、Firebase、阿里云RDS等。Vercel部署的前端通过环境变量中的连接字符串访问数据库。

Vercel能处理支付吗？

支付是后端功能，不能直接放在Vercel上。但你可以在Vercel上部署前端，支付逻辑放在后端服务（如Stripe、Supabase Edge Functions）。前端只负责展示支付界面和跳转。

不想用CLI，还有别的方式部署吗？

有。直接拖拽文件夹到 Vercel Dashboard 就完成部署。或者通过GitHub集成，每次push自动触发部署。CLI只是其中一种方式。

Vercel和Netlify有什么区别？

两者定位相似，都是前端部署平台。Vercel对Next.js支持更好（毕竟是亲儿子），Netlify对静态网站支持更成熟。功能上差别不大，选一个用就行。OPC更推荐Vercel，因为和GitHub集成更顺畅。

Vercel使用总结

  • 免费额度足够个人项目使用
  • 零运维，专注代码本身
  • 自动HTTPS和全球CDN
  • GitHub集成，Push即部署
  • 预览部署让协作更高效
  • 遇到问题查官方文档，或在GitHub提Issue

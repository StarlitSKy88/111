02 · 快速上手

下载安装与首次启动

下载安装

访问Trae官网或应用商店下载。Trae支持macOS、Windows、Linux全平台。

# macOS # 方式一：官网下载 .dmg 安装包 # 方式二：如有 homebrew 可能可用（待确认） # Windows # 从官网下载 .exe 安装包 # 首次启动后会引导配置

首次启动配置

  1. 打开Trae，进入欢迎界面
  2. 登录账号（推荐使用Google/GitHub授权，或手机号注册）
  3. 选择界面语言（推荐简体中文）
  4. 选择主题（Dark/Light，推荐Dark墨色主题）
  5. 导入VS Code设置（如之前使用VS Code）
  6. 完成初始化，进入主界面

基础设置

推荐配置项

Editor → 字体大小：14-16px（根据屏幕大小调整）

Editor → Tab 大小：2或4（根据项目规范）

AI → 默认模型：Claude 3.5 Sonnet（推荐编程）或 Deepseek R1

AI → 快捷键：熟悉 Cmd+K 调出AI对话

项目初始化

在Trae中打开项目目录后，等待AI索引完成。索引过程决定了AI对项目上下文的理解质量。

# 首次打开项目后 # 观察左下角状态："正在索引项目..." # 索引完成后即可使用AI功能 # 使用 Cmd+K 调出AI对话 # 使用 Cmd+L 打开Composer面板

项目规则文件：Trae支持项目级AI行为配置，可在项目根目录创建配置文件定义代码规范和技术栈。这有助于AI生成符合项目风格的代码。

03 · 核心功能

四大核心能力

1. AI对话（Chat）

Trae的AI对话功能类似Cursor的Composer，可以在项目上下文中与AI进行自然语言交互。输入中文描述需求，AI生成对应代码。

快捷键：Cmd+K（调出AI对话）

适用场景

需求咨询："帮我设计一个用户注册模块的数据库结构"

代码审查："检查这段支付逻辑有没有安全隐患"

技术方案："我需要实现一个实时聊天功能，帮我对比WebSocket和SSE的优劣"

2. AI补全（Code Completion）

Trae提供智能代码补全功能，基于项目上下文预测下一个代码片段，支持整行、整函数甚至代码块的补全。

# 使用 Tab 键接受AI补全建议 # Cmd+→ 接受下一个词 # 示例场景 # 输入函数名和注释，AI自动补全函数实现 function calculateDiscount(price, level) { // 根据用户等级计算折扣 // AI自动补全：基于已有代码风格和项目规范生成实现 }

补全质量

Trae的补全功能在免费AI IDE中表现优秀，能够理解项目上下文，生成符合项目代码风格的补全内容。

3. 项目理解（Project Context）

Trae能够索引并理解整个项目结构，包括文件关系、依赖模块、代码风格。这使得AI能够生成更准确、更符合项目规范的建议。

  • 首次打开项目后等待索引完成（观察左下角进度）
  • 索引完成后，AI能理解代码间的引用关系
  • 可以针对整个项目提问，获得全局性建议
  • 重置索引：在设置中可找到"重置项目索引"选项

    中文Prompt高效使用指南

    Prompt结构化方法

    清晰、结构化的Prompt能够显著提升AI输出质量。以下是推荐的Prompt撰写方法：

    推荐结构

    1. 明确任务类型：创建/修改/审查/解释/优化

    2. 具体需求描述：功能点、技术要求、约束条件

    3. 参考上下文：参考哪个文件、哪种模式

    4. 输出格式：期望的代码风格、注释规范

    # 示例：结构化中文Prompt 任务：创建一个商品展示组件 需求： 1. 使用React函数组件 + Tailwind CSS 2. 接收product对象作为props 3. 显示商品图片（默认图）、名称、价格 4. 价格显示格式化（¥123.00） 5. 点击图片放大预览（使用已有Lightbox组件） 参考：项目中 /components/ProductCard.tsx 的代码风格 输出：完整组件代码，包含PropTypes定义 # AI会基于以上结构化信息生成高质量代码

    常见场景Prompt模板

    创建新功能

    "创建一个用户资料编辑页面，包含：头像上传、昵称修改、邮箱绑定。使用React + Formik，参考项目中的表单样式。"

    代码审查

    "审查 /api/order.ts 的支付逻辑，检查：1）安全性 2）错误处理 3）边界条件。列出问题并给出修复建议。"

    Bug修复

    "登录接口偶发500错误，可能原因：1）并发请求 2）数据库连接 3）Token验证。请帮我分析并修复。"

    技术方案

    "我需要实现一个文件上传功能，支持：1）进度显示 2）断点续传 3）大文件分片。请对比方案并给出推荐。"

    迭代优化技巧

    AI初次输出可能不完全符合预期，需要迭代优化。推荐方法：

    # 第一轮：提出初始需求 "帮我创建一个用户注册API" # 第二轮：补充细节 "加上邮箱验证，参考项目中 /api/auth/sendCode.ts 的实现方式" # 第三轮：优化质量 "增加更详细的错误提示，使用项目统一的错误格式 { success, data, error }" # 通过多轮对话逐步优化，直到满足需求

    核心原则：像与同事交流一样与AI对话。说清楚做什么、为什么做、怎么做，AI就能给出符合预期的结果。

    08 · 常见问题

    FAQ

    Trae和Cursor是什么关系？
    Trae是字节跳动开发的AI代码编辑器，Cursor是另一家公司的产品。两者都基于VS Code fork，但功能和定位有所不同。Trae主打免费+中文，Cursor功能更成熟但需要付费。
    Trae免费版有没有使用限制？
    有，免费版每日有AI使用额度限制。具体限额根据官方政策可能调整。对于MVP开发阶段，免费额度通常足够使用。
    Trae需要代理才能使用吗？
    不需要。Trae面向中国大陆用户开发，可以直接访问，无需代理。这与Cursor、GitHub Copilot需要网络代理的情况不同。
    我的代码会不会被用于训练？
    建议查看Trae官方隐私政策了解详情。一般情况下，AI代码编辑器的代码不会直接用于公开模型训练。
    Trae支持哪些编程语言？
    支持所有主流编程语言，包括但不限于：JavaScript/TypeScript、Python、Go、Rust、Java、C++、C#、PHP、Ruby、Swift、Kotlin等。
    Trae支持微信小程序开发吗？
    支持。Trae针对中国特色的小程序开发场景做了专门优化，支持微信小程序、字节小程序的开发、调试和发布。
    如何切换AI模型？
    在设置或AI对话界面中可以切换模型。Trae支持Claude、GPT、Deepseek、Gemini等多种模型，可根据任务类型和个人偏好选择。
    Trae卡顿或响应慢怎么办？
    1. 检查网络连接 2. 切换到响应更快的模型（如Gemini Flash）3. 重置项目索引 4. 确认没有大规模文件扫描任务正在运行
    OPC适合用Trae还是Cursor？
    推荐优先使用Trae（免费+中文+国内可直接访问）。如果AI使用量增加，可考虑升级Cursor Pro或使用Claude Code配合。两者并不互斥，可以根据场景选择。

    Trae学习路径

    • 第一天：下载安装，熟悉界面，体验AI对话（Cmd+K）
    • 第二天：使用AI创建一个简单功能，测试补全效果
    • 第三天：打开一个现有项目，测试项目上下文理解能力
    • 第四天：使用中文Prompt完成一个功能模块开发
    • 第五天：整合工作流，确定AI辅助开发的最佳场景

    记住：Trae是免费的，不花一分钱即可获得AI辅助编码能力。开始使用就是最重要的步骤。

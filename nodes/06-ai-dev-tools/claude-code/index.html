06 / AI开发工具

Claude Code

Anthropic官方出品的终端CLI编码代理。200K上下文、自主执行能力最强、适合自动化脚本、测试生成、复杂重构。OPC的"全天候远程工程师"。

最后修订：2026年5月13日 · 官方文档：claude.ai
一、核心定位

Claude Code是什么

Claude Code是Anthropic发布的官方CLI工具，本质上是一个可以自主执行复杂编码任务的AI代理。与IDE插件不同，它运行在终端里，接收自然语言指令后自主规划、执行、测试、修复。

核心竞争力

超长上下文：200K token，能一次性理解整个中型项目的代码结构、数据库Schema、API路由之间的全部关系。

自主执行：可以接收"把这个项目的支付模块从Stripe迁移到微信支付"这种级别的指令，自己规划步骤、执行、测试、修复，整个过程可能持续30分钟以上。

终端原生：不绑定任何IDE，在任何编辑器都可以用。可以融入现有的CLI工作流。

什么时候用Claude Code：当你有一个明确的目标任务，但需要跨越多个文件、多种技术栈、执行多步骤的时候。日常单文件补全用Cursor，复杂自主任务用Claude Code。

二、安装配置

快速上手

前置要求

  • Node.js 18+ (建议Node 20 LTS)
  • npm 或 yarn 或 pnpm
  • 有效的 Anthropic API Key (支持Claude 3.5/3.7)
  • 稳定的海外网络连接 (Clash或其他VPN)

安装步骤

# 方式一：npm全局安装（推荐） npm install -g @anthropic-ai/claude-code # 验证安装 claude --version # 方式二：npx直接运行（不安装） npx @anthropic-ai/claude-code

API Key配置

# 设置环境变量（临时，当前终端有效） export ANTHROPIC_API_KEY=sk-ant-xxxxx # 永久配置（macOS/Linux） echo 'export ANTHROPIC_API_KEY=sk-ant-xxxxx' >> ~/.zshrc source ~/.zshrc # Windows PowerShell $env:ANTHROPIC_API_KEY = "sk-ant-xxxxx"

网络问题

如果直连超时，需要配置代理。Claude Code默认读取系统代理设置。确保你的VPN/代理工具开启了"全局模式"或为Claude Code单独配置了规则。

首次启动

claude # 首次会提示选择配置： # ? Select a model to use: (Use arrow keys) # ❯ Claude 3.7 Sonnet (Recommended) # Claude 3.5 Sonnet # Claude Opus 3.5 # ? Enable telemetry? Yes/No # 建议选 No，尤其在意隐私的情况下
三、核心命令

CLI命令参考

基本用法

# 进入交互模式（推荐新手） claude # 单次任务模式（适合自动化脚本） claude "帮我把这个项目的所有console.log删掉" # 指定项目目录 claude --directory /path/to/project "分析这个项目的架构" # 安静模式（减少输出） claude --quiet "生成100个单元测试" # 输出到文件 claude "写一个README.md" > README.md

交互模式常用指令

命令说明
q 或 exit退出Claude Code
Ctrl+C中断当前任务
Ctrl+Z暂停任务，之后可恢复
help显示帮助
clear清屏
history查看命令历史

任务控制

# 在交互模式内： # 直接输入自然语言描述任务 # 例如："帮我创建一个用户注册表单，包含邮箱、密码、确认密码三个字段" # 任务执行中可用的指令： # y - 确认执行（当Claude请求权限时） # n - 拒绝执行 # a - 批准所有后续操作 # diff - 查看将要执行的变更 # l - 查看最近的操作列表
重要 权限模式

Claude Code默认在受限模式下运行，只读文件、搜索代码、执行测试。但涉及写文件、执行命令、删除文件时，会请求你的明确批准。这是为了保护你的代码安全。

当你确认Claude的操作是安全的，可以输入a（approve all）跳过后续所有确认。

管道与脚本

# 从文件读取指令 claude < task.txt # 多行指令 claude "第一个任务： 1. 创建users表 2. 创建posts表 3. 添加外键关系" # 结合Git命令 git diff | claude "审查这个diff，帮我写commit message" # 在CI/CD中使用 claude --non-interactive "运行所有测试并修复失败的"

五、MCP配置

Model Context Protocol

MCP是Anthropic推出的开放协议，允许Claude Code连接外部工具和数据源。配置MCP后，Claude Code可以直接访问你的文件系统、Git仓库、数据库等。

配置文件位置

# 全局配置 ~/.claude/mcp.json # 项目级配置 ./.claude/mcp.json

常用MCP服务器

服务器功能安装
filesystem读写本地文件内置
gitGit操作内置
memory跨会话记忆npm install
slack发送Slack消息npm install
githubGitHub APInpm install
postgresPostgreSQL查询npm install

配置示例

# ~/.claude/mcp.json { "mcpServers": { // 内置文件系统（默认开启） "filesystem": { "command": "node", "args": ["/path/to/claude-code/dist/tools/mcp/index.js", "filesystem"] }, // Git集成 "git": { "command": "node", "args": ["/path/to/claude-code/dist/tools/mcp/index.js", "git"] }, // GitHub API "github": { "command": "npx", "args": ["-y", "@anthropic-ai/claude-mcp-server", "github"], "env": { "GITHUB_TOKEN": "ghp_xxxxx" } }, // PostgreSQL数据库 "postgres": { "command": "npx", "args": ["-y", "@anthropic-ai/claude-mcp-server", "postgres"], "env": { "DATABASE_URL": "postgresql://user:pass@localhost:5432/dbname" } } } }

验证MCP配置

# 进入Claude Code后，查看已加载的工具 claude > /tools # 如果配置正确，会显示类似： # Available tools: read, edit, bash, git, github, postgres...
六、Skills与Hooks

扩展机制

Skills（技能）

Skills是预定义的行为模板，让Claude Code在特定场景下执行最佳实践。

# 创建一个新的Skill claude --skill create my-skill # 查看内置Skills claude --skills # 可用内置Skills： # - tdd: 测试驱动开发流程 # - refactor: 代码重构流程 # - review: 代码审查流程 # - docs: 文档生成流程

自定义Skill示例

创建一个确保代码符合OPC编码规范的Skill：

# ~/.claude/skills/opc-code.md # OPC编码规范检查 ## 执行步骤： 1. 检查是否有console.log/console.error 2. 检查是否有TODO/FIXME注释 3. 检查是否使用了中文注释 4. 检查错误处理是否完整 5. 检查是否使用了process.env读取环境变量 ## 报告格式： 发现N个问题： 1. [文件:行号] 问题描述 ...

Hooks（钩子）

Hooks在特定事件发生时自动触发，用于自动化工作流。

# ~/.claude/hooks.json { "hooks": { // 每次执行命令前 "pre-command": [ "echo 'Executing: $COMMAND'" ], // 每次写文件后 "post-write": [ "npx prettier --write $FILEPATH" ], // 每次任务完成后 "post-task": [ "echo 'Task completed at $(date)' >> ~/.claude/logs/tasks.log" ] } }

OPC实战组合：用pre-command钩子记录每次操作意图，post-write钩子自动格式化代码，post-task钩子生成操作日志。这套组合让你对Claude Code的所有行为都有据可查。

七、实战案例

OPC典型工作流

案例一 数据库迁移

场景：把用户表的phone字段拆成country_code和phone_number两个字段，同步更新所有相关API和前端组件。

# 启动Claude Code并执行迁移 claude # 输入： 请执行以下数据库迁移任务： 1. 修改Supabase中的users表： - 将phone字段拆分为country_code (varchar, 5) 和 phone_number (varchar, 20) - 保留phone字段作为临时列，迁移完成后删除 2. 更新后端API（位于/src/api/）： - 更新用户注册端点 - 更新用户资料获取端点 - 更新短信验证码发送端点 3. 更新前端组件（位于/src/components/）： - 更新注册表单 - 更新用户资料页面 - 更新所有显示电话号码的地方 4. 运行测试确保功能正常 # 然后输入 y 确认执行
案例二 生成测试套件

场景：为一个支付模块生成完整的单元测试和集成测试。

# 单次执行模式 claude --non-interactive "为/src/services/payment.js生成完整的测试套件，包含： - 单元测试：每个函数的正常路径和异常路径 - 集成测试：模拟Stripe Webhook回调 - 测试覆盖率目标：80%以上 - 使用Jest框架 - 测试文件命名：payment.test.js" # 如果测试覆盖率不够，Claude会自动补充
案例三 代码审查与重构建议

场景：用Git diff + Claude Code做代码审查。

# 查看当前分支的改动 git diff main...HEAD | claude "请审查这个分支的所有改动，检查： 1. 是否有潜在Bug 2. 是否有安全漏洞 3. 是否有性能问题 4. 是否符合OPC编码规范 5. 给出重构建议" # Claude会输出详细的审查报告
案例四 自动化部署检查

场景：部署前自动检查所有关键项。

# 创建一个部署前检查脚本 claude "创建一个部署前检查脚本 deploy-check.sh，包含以下检查项： 1. 运行测试（npm test） 2. 运行lint（npm run lint） 3. 检查环境变量是否完整 4. 检查数据库连接 5. 检查外部API可用性 每个检查项失败时退出码为非0"
八、常见问题

FAQ

Q: Claude Code和Cursor哪个更好？

A: 它们解决不同问题。Cursor是日常IDE伴侣，适合即时补全和小修改。Claude Code是终端代理，适合复杂的多步骤任务。对于OPC来说，建议两者都用：日常开发用Cursor，复杂任务用Claude Code。

Q: Claude Code消耗多少API配额？

A: 取决于任务复杂度。一个简单的"删除console.log"任务可能只需几美分。一个复杂的重构任务可能消耗$1-5。建议设置API使用警报（可在Anthropic后台配置）。

Q: 网络不稳定怎么办？

A: Claude Code需要稳定连接海外网络。建议使用 Clash Verge 或 Shadowsocks 等工具，并开启"全局模式"。如果频繁断连，检查代理规则是否包含了api.anthropic.com域名。

Q: 如何避免Claude Code误删代码？

A: 默认情况下，Claude Code不会自动删除文件，会请求确认。对于高风险操作（如删除多个文件），建议先用git commit保存当前状态，这样即使操作失误也可以回滚。

Q: 可以同时运行多个Claude Code实例吗？

A: 可以，但强烈不推荐。每个实例都会消耗API配额，同时运行多个实例容易造成代码冲突。建议串行使用：一个任务完成后再开始下一个。

Q: Claude Code能完全替代程序员吗？

A: 不能。Claude Code是一个强大的工具，但它需要你提供清晰的任务描述和判断结果是否正确。OPC仍然需要理解基本的编程概念，至少能读懂代码、能描述问题、能验证结果。

Q: 如何配置国内镜像加速？

A: Claude Code本身不提供镜像，但可以通过配置代理实现加速。在Clash中设置规则，让api.anthropic.com走代理。同时确保npm安装claude-code时使用国内镜像（设置npm config set registry https://registry.npmmirror.com）。

  • 配置稳定海外网络

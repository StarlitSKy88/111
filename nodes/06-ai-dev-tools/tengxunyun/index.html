06 / 云服务

腾讯云

国内OPC首选云服务。稳定、高性价比、备案便捷。覆盖域名注册、服务器部署、数据库、CDN等全链路。本教程聚焦OPC常用的核心功能。

最后修订：2026年5月14日 · 官方：cloud.tencent.com
一、为什么选腾讯云

国内OPC云服务选择

国内做网站/应用，服务器必须在国内。这是工信部规定，不存在"技术绕过"。因此阿里云和腾讯云是唯二选择。

腾讯云 vs 阿里云

维度腾讯云阿里云
价格新客首年低至¥30/年起新客首年¥36/年起
备案体验备案系统较流畅，APP备案便捷备案严格，流程较长
海外接入国际版节点多，海外用户访问好海外节点相对少
微信生态与微信深度集成，微信支付商户号申请便捷无原生微信集成
文档质量中文文档完善，社区活跃中文文档完善
学生优惠学生认证后¥1/月即可用CVM学生优惠类似

OPC建议：如果你的项目涉及微信生态（小程序、公众号、微信支付），选腾讯云。如果面向纯海外用户，选阿里云国际版。两者价格差异不大。

二、核心产品

OPC常用的腾讯云产品

必选产品

域名注册 必选

用途：网站唯一地址，如 opcone.cn

价格：首年¥1（.cn域名，部分促销），续费¥35/年

购买渠道：腾讯云域名注册

注意：需要实名认证（个人可绑身份证）

云服务器 CVM 必选

用途：部署网站后端、数据库、应用服务

价格：¥30/月起（1核1G入门款）

替代方案：如果只是静态网站，可用轻量应用服务器（¥24/月），更高性价比

ICP备案 必选

用途：国内服务器上线必须，否则会被封禁

时间：约2-3周（腾讯云代备案）

材料：身份证、网站真实性核验单、域名证书

SSL证书 必选

用途：HTTPS加密，浏览器显示"安全"标识

价格：腾讯云有免费版（TrustAsia DV）

替代：Let's Encrypt免费证书（需手动续期）

可选产品

内容分发网络 CDN

用途：加速全国用户访问，降低服务器压力

价格：按流量计费，约¥0.21/GB

建议：用户分布全国时再考虑

云数据库 MySQL

用途：替代自建MySQL，省去运维工作

价格：¥15/月起（入门款）

注意：OPC阶段可用轻量应用服务器自带MySQL

对象存储 COS

用途：存储图片、视频、文件

价格：¥0.118/GB/月（标准存储）

建议：需要存储用户上传文件时使用

云监控

用途：监控服务器CPU、内存、网络

价格：免费

建议：必开，及时发现异常

三、域名与备案

域名全流程

第一步：域名注册

  • 访问 cloud.tencent.com/domain
  • 查询想要的域名（建议 .cn 或 .com）
  • 选择年限（建议首次买1年，观察价格）
  • 完成实名认证（个人：身份证，企业：营业执照）

域名推荐

国内项目：.cn（中国域名，辨识度高）

国际项目：.com（全球通用）

创意项目：.io（技术感）、.me（个人品牌）

价格红线：不要买超过¥60/年的域名，溢价严重

第二步：ICP备案

如果服务器在大陆，必须进行ICP备案。这是国家规定，不备案的域名会被运营商封禁。

流程 备案步骤

1. 前期准备：域名（完成实名）、服务器（购买时长≥3个月）、身份证

2. 在腾讯云提交：登录备案控制台 → 开始备案

3. 填写信息：网站信息、主体信息、服务内容

4. 真实性核验：手机APP人脸识别 或 幕布拍照

5. 管局审核：腾讯云初审（1-2天）→ 管局终审（7-20天）

6. 备案成功：获得备案号，添加到网站底部

备案冷知识：一个腾讯云账号可备案5个域名。如果有多个网站，可以共用一个备案主体（个人或公司）。

第三步：域名解析

# 在腾讯云控制台 → 域名服务 → DNS解析 # 添加记录： # 记录类型 主机记录 记录值 # A @ 服务器IP # A www 服务器IP # CNAME api your-app.vercel.app # 生效时间：几分钟~24小时不等

安全组配置

安全组是服务器防火墙。腾讯云默认只开放22端口（SSH）和3389端口（Windows）。

六、费用优化

控制云成本

OPC云服务月成本红线：验证期¥30以内，MVP期¥100以内，成长期¥300以内。超过这个数，说明配置选型有问题。

省钱策略

策略一：选对时机

腾讯云常年有促销活动（618、双11、年中惠）。新客首年价格是原价的2-3折。趁促销买2-3年，锁定低价。

策略二：按需升级

不要一开始就买高配。从最低配置开始，等用户量上来再升级。腾讯云支持热升级，不影响服务。

策略三：用免费服务

SSL证书用免费的，监控用免费的，CDN前期不需要。每一项收费服务都要问"现在真的需要吗？"

策略四：学生优惠

25岁以下可直接享受学生优惠：¥1/月用CVM。需要学生认证，适合在校创业者。

七、常见问题

FAQ

Q: 腾讯云和阿里云哪个更便宜？

A: 两者价格差异不大，日常促销价基本一致。腾讯云的优势在于与微信生态的深度集成。如果不做微信相关开发，选便宜的即可。

Q: 必须备案吗？

A: 如果服务器在大陆且使用域名，必须备案。不备案的域名会被运营商封禁（DNS解析层面）。如果不想备案，可以选择香港/海外服务器，但国内用户访问速度会慢。

Q: 服务器被攻击了怎么办？

A: 立即打开云防火墙，限制来源IP。腾讯云提供免费DDoS防护（基础版）。如果是CC攻击，可能需要购买高防IP。日常做好：SSH禁用密码登录、使用强密码、开启云监控。

Q: 数据丢了怎么办？

A: 永远假设数据会丢。必须做：1）MySQL定期自动备份；2）备份文件上传到COS（对象存储）；3）重要代码提交到GitHub。腾讯云也有数据库备份功能，可以开启自动备份。

Q: 服务器卡顿了怎么办？

A: 首先用云监控查看CPU/内存/带宽占用。如果只是内存不足，可能需要重启服务或升级配置。CPU长期100%说明代码有性能问题，需要优化。带宽跑满可以考虑加CDN。

Q: 域名转移需要收费吗？

A: 域名转出免费，但转入可能需要续费一年（各注册商政策不同）。腾讯云域名转出到其他平台，通常15天内完成。

快速开始 Checklist

  • 注册腾讯云账号，完成实名认证
  • 购买域名（.cn 或 .com）
  • 购买轻量应用服务器（¥24/月起）
  • 在控制台配置安全组（开放22/80/443端口）
  • 连接服务器，配置Nginx
  • 安装MySQL，创建数据库
  • 提交ICP备案
  • 申请SSL证书，配置HTTPS
  • 部署代码，测试上线

记住：腾讯云是OPC在国内的"地基"。选好配置、做好备案、控制好成本，后面的开发工作才能顺利开展。

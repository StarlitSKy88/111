> **作者**：蕾姆（Task #3 准备）
> **日期**：2026-06-22
> **目的**：帮昴君准备朋友圈/即刻版接触话术
> **目标**：找 2-3 个免费 alpha 用户（v5.3 Lesson 9 核心）

## 0. 核心原则（v5.3 Lesson 9）

- **设计伙伴是商业验证关键路径**，AI 不能替代
- **14 天免费试用 + 1v1 文字/视频反馈（async）**
- **二元反馈**：愿不愿付费（不是"觉得怎么样"）
- **目标人群**：35 岁上下被裁的中年人（v5.1.3 ICP）
- **接触渠道**：朋友圈 + 即刻（熟人优先，避免冷启动）

## 1. 朋友圈版（30 字内）

会用 AI 帮你建一个个人品牌 + 获客方案，
你只用告诉我好不好用、愿不愿付费。

想找 2-3 个跟我情况差不多的朋友免费试用。
你不用花钱，你只用告诉我：愿不愿每月付 ¥999 继续用。
有意私我，限 3 人。

## 2. 即刻版（200 字内）

```
【找 3 个免费 alpha user · 14 天试用】

在做一个 AI 工具，定位是"1 人 MCN 公司"：
- 多轮 AI 对话帮你挖出个人品牌方向
- 4 个 Agent 矩阵帮你持续输出 + 获客
- 监控仪表盘 + 异常预警
- 14 天免费试用，到期不强转付费

适合谁：
- 35 岁上下，被裁过 / 想搞副业
- 有产品或技能想变现
- 能花 14 天每天 30 分钟试用 + 反馈

你给我什么：
- 每天 30 分钟试用
- 每周 1 次 30 分钟 1v1 反馈（视频或文字）
- 14 天后告诉我：愿不愿每月付 ¥999 继续用

我给你什么：
- 14 天全功能免费用
- 1v1 优化你的个人品牌蓝图
- 终身 8 折优惠（如果产品上线）

有意私我或评论，限 3 人。
```

## 3. 私聊版（5 轮对话剧本）

### Round 1：开场（30 秒）
```
嗨 [名字]，最近在做一个 AI 工具，自己用着挺爽的。
看到你的 [具体场景]，觉得可能适合你。
要不要花 30 秒听我说一下？
```

### Round 2：价值主张（30 秒）
```
我做的叫 ONE-MCN，就是用 AI 帮你建一个"一人公司"：
1. 多轮 AI 对话挖出你的个人品牌方向（10 分钟）
2. 4 个 Agent 帮你持续输出内容 + 自动获客
3. 监控 + 预警 + 续费一条龙

你不用写代码，不用懂 AI，我帮你做完。
你只用每天 30 分钟看结果 + 给反馈。
```

### Round 3：时间投入 + 反馈机制（30 秒）
```
14 天免费试用，每天 30 分钟。
每周 1 次 30 分钟 1v1 反馈（视频或文字都行）。
14 天后我只要一个答案：愿不愿每月付 ¥999 继续用？
如果不愿意，我也不会催你。
```

### Round 4：风险消除（30 秒）
```
我知道你担心什么：
- 不确定能不能用 → 我 14 天不要钱，你随时可以走
- 没时间 → 我每天只花你 30 分钟，剩下的 AI 做
- 怕被骗 → 朋友圈熟人，应该知道我不是骗子

只要你能做到：每天 30 分钟 + 每周 1 次反馈，
其他全部我来搞定。
```

### Round 5：CTA（10 秒）
```
有意的话，我明天就把试用链接发你。
如果没兴趣也没关系，江湖再见。
```

## 4. 反馈采集（试用开始后）

### 每日反馈（30 秒）
```
今天用了 [功能]，感觉 [好/不好/中性]。
最大的疑问是 [一句话]。
```

### 每周反馈（30 分钟 1v1）
- 上周最爽的 3 个瞬间
- 上周最难受的 3 个瞬间
- 最想砍掉的功能
- 最想加的功能
- 愿不愿每月付 ¥999 继续用？（必问）

### 14 天终局反馈（必问 3 个问题）
1. 你会每月付 ¥999 继续用吗？（是/否/看情况）
2. 你会推荐给朋友吗？（NPS 0-10）
3. 如果不要钱，你会推荐给朋友吗？（对照付费意愿）

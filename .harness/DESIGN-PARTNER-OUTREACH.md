## 7. 14 天终局二元反馈（关键问题）

### 问题 1（必问）：付费意愿
```
14 天试用结束。
你会每月付 ¥999 继续用吗？

A. 是 → 我会跟进 Tier 选择
B. 否 → 我会问原因
C. 看情况 → 我会问什么情况下会
```

### 问题 2（必问）：NPS
```
你会向朋友推荐 ONE-MCN 吗？

0 — 完全不会
1-6 — 不太会
7-8 — 可能
9-10 — 一定会
```

### 问题 3（必问）：免费推荐
```
如果产品永久免费，你会推荐给朋友吗？

是 / 否
```

**对比付费 vs 免费意愿**：差距 = 产品的"价格敏感性"。如果免费 100% 推荐但付费只有 30% → 价格是主要阻力。

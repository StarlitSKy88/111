# 节点50：广告合规

> **面向OPC**：90% 的 OPC 在广告上栽过——"最 / 第一 / 100% / 立即赚钱"等词 = 罚款 20 万。**OPC 广告文案必须自查**。

---

## 一、《广告法》绝对不能用的 9 个词

| 类别 | 禁用词 |
|:---|:---|
| **极限词** | 最 / 第一 / 唯一 / 顶级 / 国家级 |
| **承诺词** | 100% / 包过 / 必赚 / 绝对 / 保证 |
| **医疗** | 治愈 / 根治 / 药到病除 |
| **金融** | 稳赚不赔 / 无风险 / 高收益 |
| **虚假** | 立即 / 马上 / 1 天学会 / 月入百万 |
| **比较** | 最好 / 最佳 / 销量冠军（无可证明）|
| **保证** | 包退 / 包过 / 包学会 |
| **国家** | 央视推荐 / 国家级 / 领导品牌 |
| **其他** | 永久 / 终身 / 0 风险 |

**用了 = 罚款 20 万起步**。

---

## 二、3 个 OPC 高频踩雷区

### 雷区 1：朋友圈 / 公众号宣传

**症状**："我们是最专业的 OPC 工具"
**解法**：把"最"换成"我们的" / "我们提供"。

### 雷区 2：落地页 CTA

**症状**："100% 学会" / "月入 10 万不是梦"
**解法**：用具体数据 + 来源："30 天学会，参考 2025 年 XXX 用户访谈"。

### 雷区 3：产品功能介绍

**症状**："AI 自动生成 100% 准确的内容"
**解法**：用"通常" / "在多数情况下" / "参考 XX 行业数据"。

---

## 三、3 个安全的替代表达

| 错误 | 安全替换 |
|:---|:---|
| "最好用的工具" | "受到 1 万用户好评" |
| "月入 10 万" | "年营收 100 万 + 的用户案例" |
| "100% 解决问题" | "已帮助 1000+ 用户解决类似问题" |
| "第一选择" | "众多用户的共同选择" |
| "立即见效" | "通常 1-3 天可看到初步效果" |
| "包学会" | "配套 1V1 答疑服务" |
| "永久免费" | "目前免费，未来可能调整" |
| "独家" | "专注于 XX 领域" |

---

## 四、3 个场景的具体合规

### 1. 直播带货

- 必须展示品牌资质
- 不能虚假宣传"全网最低价"
- 必须有"商品"字样
- 不能承诺"无效退款"模糊话术

### 2. 知识付费课程

- 不能"包学会" / "包就业"
- 必须标注"最终效果因人而异"
- 不能"年入百万"等承诺

### 3. SaaS 工具广告

- 不能"最"系列
- 不能"100%"承诺
- 退款政策必须明确

---

## 五、3 个不能省的"免责条款"

每篇产品介绍末尾**加 1 段**：

```
本文所述效果为特定用户案例，
实际效果因个人情况而异，
请理性评估后决策。
```

**注意**：免责条款不能免除欺诈责任。

---

## 六、3 个 OPC 实操检查清单

发布前自查：

- [ ] 全文无"最 / 第一 / 100%"等极限词
- [ ] 无"包 / 必 / 绝对"等承诺词
- [ ] 数据都有来源（"经 1000 用户调研"）
- [ ] 案例有具体姓名/链接（非杜撰）
- [ ] 末尾有"效果因人而异"声明
- [ ] 价格 / 退款政策写清楚

---

## 七、3 个真实的罚款案例

| 案例 | 违规 | 罚款 |
|:---|:---|:---:|
| 某在线教育 | "保过" | 50 万 |
| 某医美 App | "100% 有效" | 30 万 |
| 某理财课程 | "月入 10 万" | 20 万 |

**OPC 第一年**踩 1 次 = 1 年白干。

---

## 八、被处罚后的 3 个补救

1. **立即删除**违规内容（减轻情节）
2. **主动联系**市场监管局说明情况
3. **找律师**准备听证（部分可减罚）

**金额 < 5 万** = 简易程序，主动配合可减 50%。
**金额 > 20 万** = 必请律师。

---

## 九、检查清单

- [ ] 落地页 / 公众号无极限词
- [ ] 产品介绍有"效果因人而异"声明
- [ ] 退款政策明确
- [ ] 直播话术合规
- [ ] 营销话术由法务/懂行的人过目
- [ ] 每年 1 次合规培训

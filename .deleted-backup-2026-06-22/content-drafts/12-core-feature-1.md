# 节点12：核心功能1开发

> **面向OPC**：环境搭好了，数据库通了，现在写第一行真正创造价值的代码。核心功能1是你产品的灵魂——用户打开产品就是为了用它。本节点告诉你：怎么一个人把第一个核心功能做出来，而且做对。

---

## 一、先定义，再编码

### 核心功能1的一句话定义

> [用户] 通过 [操作] 获得 [结果]

| 产品 | 一句话 |
|---|---|
| OPC节点百科 | 创业者通过节点导航，找到下一步该做什么 |
| AI简历优化 | 求职者上传简历，3分钟拿到优化建议 |
| 记账工具 | 用户记录收支，看到本月花了多少钱 |

**如果你写不出这句话，说明你还没想清楚。别写代码。**

---

## 二、2026年OPC开发核心功能1的最优路径

### 路径：AI辅助 + 分步验证

```
1. 用AI生成第一版代码（10分钟）
2. 本地跑通核心流程（30分钟）
3. 接入真实数据（1小时）
4. 处理错误状态（30分钟）
5. 加Loading/Empty/Error三种状态（30分钟）
──────────────────────────────
总计：≈3小时完成核心功能1的80%
```

### 步骤1：用AI生成第一版

在Cursor中打开项目，用这个prompt模板：

```
我在做一个[产品描述]，技术栈是[前端框架]+Supabase。
请帮我实现核心功能：[一句话定义]
要求：
1. 只需要一个页面，包含输入区和结果展示区
2. 用Supabase存取数据（表名：[表名]）
3. 不做登录（先用匿名方式）
4. 样式简洁，移动端友好
```

### 步骤2：本地跑通

```
打开浏览器 → 输入数据 → 点提交 → 看到结果 → 检查Supabase表中是否有数据
```

**如果这5步有任何一步卡住了 → 回去改prompt重新生成，不要手动改代码。**

### 步骤3：三种状态的处理

核心功能1必须覆盖三种状态（否则用户会觉得产品是坏的）：

```javascript
// 状态1：加载中
if (loading) return '<div class="loading">分析中...</div>';

// 状态2：空状态（首次使用）
if (!data) return '<div class="empty">上传你的简历，开始第一次分析</div>';

// 状态3：错误
if (error) return '<div class="error">出错了：${error.message}，请刷新重试</div>';

// 正常展示
return renderResult(data);
```

## 三、核心功能1的完成标准（上线前自检）

| 标准 | 检查方式 |
|---|---|
| 输入→输出完整链路 | 无痕浏览器，从头走一遍 |
| 数据持久化 | 刷新页面，数据还在 |
| 三种状态都有 | 分别触发Loading/Empty/Error |
| 移动端可用 | 手机微信打开，核心流程走通 |
| 20秒内完成操作 | 计时：从打开到看到结果≤20秒 |

## 四、最容易犯的两个错误

### 错误1：想要"完美"的第一版

❌ 做了3天还在调UI颜色和动画  
✅ 功能跑通就停手。UI优化等节点14一起做。

### 错误2：跳过错误处理

❌ "这个输入框用户不会填错的"  
✅ 空输入、超长输入、特殊字符全部处理。自己测试时用真实数据，别用"test"。

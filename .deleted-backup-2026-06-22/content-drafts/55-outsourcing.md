# 节点55：外包策略与执行

> **面向OPC**：OPC 一个人，但**某些事必须外包**——设计、客服、3 天以上的体力活。本节点告诉你**怎么雇人不被坑**。

---

## 一、OPC 必外包的 5 类事

| 类别 | 自己做的成本 | 外包的成本 | 外包理由 |
|:---|:---|:---|:---|
| **Logo / UI 设计** | 3 天 = 0 收入 | 500-3000 元 | 速度快 10 倍 |
| **客服 / 答疑** | 每天 2 小时 | 2000-5000/月 | 时间复用 |
| **短视频剪辑** | 1 天学不会 | 100-500/条 | 专业工具 |
| **数据标注 / 录入** | 1 周 | 500-1500 | 重复劳动 |
| **海外推广** | 0 渠道 | 1-3 万/月 | 资源杠杆 |

**OPC 永远算"机会成本"**：你 1 小时值 200 元，外包 100 元 = 净赚 100 元。

## 二、3 个主流外包渠道

### 1. 国内兼职平台

| 平台 | 适合 | 价格 |
|:---|:---|:---|
| **猪八戒** | 设计 / 简单开发 | 中 |
| **电鸭社区** | 远程兼职 / 程序员 | 中 |
| **闲鱼 / 豆瓣** | 小活 / 设计 | 低 |
| **即刻动态** | 高质量自由职业 | 中高 |

### 2. 海外平台

| 平台 | 适合 | 价格 |
|:---|:---|:---|
| **Upwork** | 全球程序员 / 设计 | 中高 |
| **Fiverr** | 小活 / 标准化任务 | 低 |
| **Toptal** | 高端人才（前 3%）| 高 |

### 3. AI 工具（最便宜）

| 工具 | 替代 |
|:---|:---|
| **Coze / Dify** | 客服 |
| **Cursor / Claude Code** | 编程 |
| **Midjourney / GPT-4o** | 设计 |
| **ElevenLabs** | 配音 |

**OPC 优先用 AI 工具**——便宜 + 24 小时在线。

## 三、3 步找到靠谱外包

### Step 1：写清晰的"工作说明书"

**错误**："帮我做一个 logo"
**正确**：
```
需求：SaaS 工具 logo，名称"蕾姆"
风格：极简 / 暗色 / 朱红强调色
尺寸：512x512, 1024x1024, SVG
参考：附件 3 张竞品
预算：500-1500 元
交付：Figma 源文件 + PNG 5 个尺寸
时间：3 天
```

**写得越细 = 越少返工**。

### Step 2：先小单测试

- 第一单 100-300 元
- 测 3 个候选人
- 看 1 个完整工作流

### Step 3：长期合作前先建立信任

| 信号 | 含义 |
|:---|:---|
| 准时交付 | 靠谱 |
| 主动提建议 | 走心 |
| 超预期完成 | 值得长期 |
| 经常迟到 | 换人 |
| 交付不符 | 立即停止合作 |

## 四、3 个 OPC 必签的合同条款

### 1. 知识产权归属

```
乙方为甲方创作的所有工作成果（包括但不限于设计稿、代码、文档），
其知识产权归甲方所有，乙方不得保留或转让。
```

**没有这一条 = 外包方可以拿你的设计 / 代码再卖给别人**。

### 2. 保密协议（NDA）

```
乙方对甲方提供的产品信息、商业计划、客户数据等保密，
未经书面同意不得向第三方披露。
```

**OPC 必备**——你把产品思路告诉设计师，设计师可能卖给你的竞品。

### 3. 退款条款

```
若乙方在 X 天内未交付，甲方有权终止合作并要求退款（已交付部分除外）。
```

## 五、3 个 OPC 外包支付方式

### 1. 分阶段付款

| 阶段 | 比例 |
|:---|:---:|
| 启动 | 30% |
| 初稿交付 | 30% |
| 修改完成 | 30% |
| 最终交付 | 10% |

### 2. 平台托管

猪八戒 / Upwork 等平台有托管支付，**验收后才打款**给乙方。

### 3. 试用 1 周再签长期

第一次合作不要签年付，按月或按项目结算。

## 六、3 个必会的外包管理技巧

### 1. 用 Notion / Trello 管理任务

不要用微信来回调任务 = 后期全乱。

### 2. 每天 15 分钟同步

早上 9 点 / 晚上 9 点 = 两次 check-in。

### 3. 验收清单（SOP）

每次交付都过：
- [ ] 是否符合需求文档
- [ ] 文件格式是否正确
- [ ] 源文件是否提供
- [ ] 知识产权是否转让

---

## 七、3 个常见坑

### 坑 1：最便宜 = 最好

**错**。**99% 的便宜 = 质量差 + 重新做**。
**OPC 真理**：花 1000 元做对 = 比花 500 元做错重做 3 次便宜。

### 坑 2：一个人做所有事

**错**。OPC 不是 996 的码农。
**真理**：雇人 = 你赚更多 = 业务增长。

### 坑 3：签了合同就不管

**错**。合同是底线，**日常沟通**才是关键。
**建议**：每周 1 次 30 分钟视频同步。

## 八、3 个 OPC 必算的账

| 指标 | 公式 | 健康 |
|:---|:---|:---:|
| 雇人 ROI | 外包产出营收 / 外包成本 | > 3 |
| 时间节省 | 雇人省的小时 × 时薪 | > 0 |
| 长期成本 | 月度固定外包 / 月营收 | < 30% |

# 节点46：现金流与财务基础

> **面向OPC**：OPC 死亡的 #1 原因不是产品不好，是**现金流断裂**。本节点给你一个**1 小时的现金流模型**，让你提前 6 个月知道会不会断粮。

---

## 一、现金流的 3 个真相

| 真相 | 后果 |
|:---|:---|
| **利润 ≠ 现金** | 看起来赚 10 万，银行只有 1 万 |
| **收入 ≠ 到账** | 客户说付 = 不等于付了 |
| **支出永远是即时的** | 服务器/工资当天扣，**不会等你** |

**OPC 的核心任务**：**保持银行账户 ≥ 6 个月固定支出**。

---

## 二、现金流模型（1 小时搞定）

### Step 1：列所有支出

| 类别 | 金额/月 | 备注 |
|:---|:---:|:---|
| 个人生活费 | ¥5000 | 房租 + 吃饭 + 交通 |
| 服务器/工具 | ¥200 | Vercel + 域名 + 监控 |
| 营销 | ¥500 | 投流 + 内容 |
| 代账 | ¥300 | 个体户代账 |
| 应急储备 | ¥1000 | 留 20% 缓冲 |
| **总计** | **¥7000** | 每月固定支出 |

### Step 2：算 Runway（跑道）

```
Runway（月）= 现金储备 / 月固定支出
```

**健康值**：Runway ≥ 12 个月 = 安全
**警告**：Runway < 6 个月 = 找收入
**紧急**：Runway < 3 个月 = 必须工作/兼职/融资

### Step 3：算 LTV / CAC

```
LTV = 用户终身价值 = ARPU × 平均生命周期月数
CAC = 获客成本 = 营销支出 / 新增付费用户

健康：LTV ≥ 3 × CAC
```

### Step 4：算 Break-even（盈亏平衡）

```
每月付费用户数 = 月固定支出 / ARPU
例：7000 / 29 = 241 个付费用户
```

**目标**：12 个月内达到 Break-even。

## 四、3 个致命陷阱

### 陷阱 1：以为"应收账款 = 现金"

**症状**：账上 5 万应收，实际银行 5000。
**解法**：客户超过 30 天未付 = 暂停服务。

### 陷阱 2：盲目扩张支出

**症状**：营收 1 万，团队 5 个人。
**解法**：OPC 永远先验证收入再扩张。

### 陷阱 3：不分"公司钱"和"个人钱"

**症状**：把营收当生活费。
**解法**：每月固定给自己发"工资"（如 5000），剩下的留公司。

## 六、3 个现金管理技巧

### 1. 备用金 = 6 个月支出

**放余额宝 / 货币基金**：随时可取 + 年化 2%。

### 2. 收入分账户

| 账户 | 用途 | 比例 |
|:---|:---|:---:|
| 经营账户 | 收客户款 | 100% |
| 个人账户 | 每月发自己工资 | 30% |
| 储备账户 | 应急 / 扩张 | 50% |
| 税账户 | 季度报税预留 | 20% |

### 3. 季度审视

每 3 个月：
- 重新算 Runway
- 调整预算
- 砍掉亏钱产品/服务

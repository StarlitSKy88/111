# 节点49：软件著作权登记

> **面向OPC**：软件著作权（简称"软著"）= 你的代码属于你的法律证明。**OPC 上线后必做**，否则被抄袭维权无门。

---

## 一、软著的 3 个核心价值

| 价值 | 场景 |
|:---|:---|
| **法律权属证明** | 别人抄你的代码，你可以起诉 |
| **上架应用商店** | App Store / 小程序 / 应用市场都需要 |
| **高新企业认定** | 减税 + 政府补贴 + 投标加分 |

**成本**：自己办 100 元 / 加急 300 元。**性价比极高**。

---

## 二、3 个常见误区

### 误区 1：代码自动有著作权

**部分对**。中国《著作权法》自动保护"作品"，但**没有登记证书** = 维权困难。
**OPC 解法**：100% 要做登记。

### 误区 2：需要代码全部文档

**错**。只需要提交 30 页**前 + 后**代码 + 用户手册。

### 误区 3：需要等产品上线

**错**。从写出第一行代码就可以申请。

---

## 三、3 步软著登记流程

### Step 1：准备材料（2-3 天）

| 材料 | 要求 |
|:---|:---|
| **软件著作权登记申请表** | 中国版权保护中心网站下载 |
| **源代码 30 页** | 前 30 + 后 30 页，每页 50 行 |
| **用户手册 / 文档** | 15-30 页，含功能介绍 |
| **申请人身份证明** | 个人身份证 / 公司营业执照 |
| **权利归属证明** | 独立开发说明（公司申请） |

**代码准备要点**：
- 删除注释（避免和他人代码撞）
- 去掉 git 提交信息里的作者名
- 添加版权声明（每页顶部 `@copyright 2026 OPC`）

### Step 2：在线提交

1. 打开 [中国版权保护中心](https://www.ccopyright.com.cn)
2. 注册账号 → 实名认证（1-2 天）
3. 填写申请表 + 上传材料
4. 缴纳费用：100 元（普通）/ 300 元（加急 30 天）

### Step 3：审查 + 拿证

| 类型 | 时间 | 费用 |
|:---|:---:|---:|
| 普通 | 60 个工作日 | 100 元 |
| 加急 30 天 | 30 个工作日 | 300 元 |
| 加急 15 天 | 15 个工作日 | 500 元 |

**OPC 推荐**：普通 100 元即可，不急。

## 四、源代码 30 页生成技巧

### 用 cloc + pandoc 一键生成

```bash
# 安装 cloc
npm install -g cloc

# 统计代码行数
cloc src/ --include-lang=JavaScript,TypeScript

# 生成前 30 页
cat src/index.ts > code_front.txt
# ... 重复直到 30 页（约 1500 行）

# 用 pandoc 转 PDF
pandoc code_front.txt -o front.pdf --pdf-engine=xelatex
```

### 提交格式

每页 50 行，单倍行距，宋体小 4 号字，顶部加：
```
软件名称：XXX
版本号：V1.0
页码：1/30
```

## 五、用户手册模板

**OPC 推荐结构**（15-30 页）：

```
1. 引言
   1.1 编写目的
   1.2 项目背景
2. 软件概述
   2.1 目标
   2.2 功能
   2.3 运行环境
3. 安装与初始化
4. 功能说明（每个核心功能 1-2 页）
5. 操作流程
6. 常见问题
```

**不要写**："本文档包含商业机密" — 软著文档是**公开**的。

## 六、3 个软著应用场景

### 场景 1：App Store / 应用市场上架

**必须**。没有软著 = 不能上架收费 App。

### 场景 2：政府补贴申报

**如**：高新技术企业的 5 万元补贴，软著是基础材料。

### 场景 3：维权诉讼

被抄袭时，软著证书 = 最直接的权属证明。

---

## 七、3 个常见错误

### 错误 1：代码用模板生成

**症状**：用 create-react-app / Next.js 脚手架生成的代码，**不算独创**。
**解法**：必须有 60% 以上自主开发代码。

### 错误 2：用户手册只放截图

**错**。必须含文字说明 + 流程图 + 功能描述。

### 错误 3：等"产品完美"再申请

**错**。每个里程碑版本都可以申请。
**OPC 解法**：V1.0 上线后立刻申请，V2.0 再申请 1 个。

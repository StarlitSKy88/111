# 节点02：个人能力与资源盘点

> **面向OPC**：在写第一行代码之前，先问自己一个问题——"我一个人，能把这个生意从头到尾跑通吗？"83%的一人公司失败，不是产品不好，是创始人根本没准备好。

---

## 一、2026年OPC的能力自检矩阵

### 不是"你会什么"，而是"你缺什么"

| 能力域 | 自检问题 | 最低要求 | 不会怎么办 |
|---|---|---|---|
| **产品** | 你能独立做出一个能用的产品吗？ | 用AI+Cursor从零做出一个网页 | 2026年AI工具让零基础也能做（见节点06） |
| **获客** | 你知道你的前10个用户在哪吗？ | 有一个群/一个论坛/一个社交账号，里面有你的目标用户 | 从朋友圈开始（见节点32） |
| **变现** | 你能说清楚为什么别人要付钱吗？ | 用一句话说清楚"付了钱能得到什么" | 先免费验证需求，再定价 |
| **运营** | 你愿意每天花1小时回复用户吗？ | 愿意 | 如果"不愿意"——别创业 |
| **合规** | 你知道怎么合法收钱吗？ | 了解个体户vs公司的区别 | 见节点23 |

### OPC最致命的三种"以为自己行"

1. **"我会写代码=我能做产品"** → 不对。做产品=理解用户+设计+开发+上线+维护。代码只占20%
2. **"我认识很多人=我有客户"** → 不对。认识的≠会付钱的。朋友圈500人，愿意付你钱的往往不超过10个
3. **"我有存款=我能撑到赚钱"** → 不对。存款÷月支出=你的倒计时。2026年一个人的月生活成本至少¥5000（一线城市¥8000）。10万存款=20个月倒计时

---

## 二、资源盘点：不是你有多少钱，而是你有多少时间

### 2026年OPC的三种启动资源

| 资源类型 | 充足 | 紧张 | 危险 |
|---|---|---|---|
| **时间** | 每天≥6小时可投入 | 每天2-4小时（有主业） | 每天<2小时（几乎不可能） |
| **资金** | ≥12个月生活费 | 3-12个月生活费 | <3个月生活费 |
| **人脉** | 目标行业内有10+个可请教的联系人 | 有3-5个同路人 | 零人脉（但可以从零建） |

### 时间的真实成本

2026年一个OPC的时间价值：
- 你的时间=0元/小时（还没有收入时）
- 但外包的时间=¥100-500/小时（请人帮你做）

**这意味着**：如果你月生活费¥6000，外包一个功能¥3000=你半个月的命。所以能自己做的绝对不外包。这也是为什么2026年AI工具对OPC如此重要——它把你的时间价值从¥0/小时提到了¥100/小时。

## 三、2026年OPC能力补全路径

### 不会技术 → AI工具补

| 需要的能力 | 2026年替代方案 | 学习时间 |
|---|---|---|
| 写前端页面 | Cursor + prompt → 自动生成 | 0天（描述需求即可） |
| 搭后端 | Supabase → 零代码建表+自动API | 半天 |
| 做设计 | v0.dev / bolt.new → AI生成UI | 0天 |
| 部署上线 | Vercel → git push自动部署 | 1小时 |

### 不会获客 → 内容补

| 需要的能力 | 2026年替代方案 | 学习时间 |
|---|---|---|
| SEO | 用AI写文章 → 发布到知乎/掘金/公众号 | 半天学会发布 |
| 社交媒体 | 每天发1条价值内容（小红书/即刻/X） | 0天（你本来就会发） |
| 广告投放 | 先用内容验证需求，广告是放大不是创造 | 等月入过万再学 |

## 四、盘点后的三种决策

| 你的情况 | 建议 |
|---|---|
| 技术+获客都有基础 | ✅ 直接开干。你有6-12个月窗口期 |
| 只有技术，不会获客 | ⚠️ 先花1个月在目标社区建立存在感（每天写一条有价值的评论/帖子），再做产品 |
| 只有获客，不会技术 | ⚠️ 先用AI工具试做一个最简版本（见节点04原型），不行再找技术合伙人 |
| 两者都不会 | ❌ 先学会一样。建议先学AI辅助开发（2周），再做最小产品验证 |

## 五、检查清单

- [ ] 能力五域自检完成（产品/获客/变现/运营/合规）

- [ ] 时间/资金/人脉资源已量化（倒计时数字已写下来）
- [ ] 能力缺口已有补全方案（AI工具或学习计划）
- [ ] 已做出明确决策：开干/先补能力/不适合现在创业

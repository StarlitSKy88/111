Git 版本管理
分支策略 + 提交规范

1 人也要用 Git

1 人 MCN 「Git 版本管理」完整 SOP · 14 节点中第 1 个

20 min 读完 1 人 可做 阶段 P1 产品阶段

为什么 1 人 MCN 要用 Git？

  • ① 视频脚本迭代需要版本回溯（D5 视频比 D1 强太多）
  • ② 配置文件管理（豆包 TTS 参数表 / 剪映预设）
  • ③ 内容日历版本化（飞书表格 / 飞书 wiki 配合）
  • ④ 多设备同步（Mac 剪 + Win 审）

1 人 MCN 简化版 Git Flow

  • main：稳定可用（线上在跑的脚本/配置）
  • dev：日常开发（每天 commit）
  • feature/*：单个钩子脚本实验（用完即弃）
  • → 1 人项目不需要 hotfix/release 分支

提交规范

  • feat: 新增 1 个钩子脚本
  • fix: 修复 TTS 合成问题
  • docs: 更新内容日历
  • test: 测试新模板
  • chore: 杂项（更新豆包模型等）

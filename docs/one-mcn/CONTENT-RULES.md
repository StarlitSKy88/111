## ✅ 1. A4 脚本风格（字数 + 表达）

**规则**：
- **字数**：90-120 字（45 秒口播）
- **风格**：对话体（1-2 句对话开场）
- **基线**：「我跟你说啊，XX？…（引入话题）」开头，避免"今天我们来讲…"式教学开场

**示例**：
```
我跟你说啊，一个人公司真的能活吗？
就拿老张来说，3 年前他被裁员，今年他一个人做了 1 个小程序，月入 3 万。
他没雇人、没融资、就 1 个人 + 1 套 AI。
想看他怎么做的？评论区扣 1。
```

## ✅ 2. A4 脚本结构（4 段式）

**结构**：**反问 → 案例 → 总结 → CTA**

| 段 | 字数 | 内容 |
|:---:|:---:|:---|
| 1 反问 | 15-20 字 | 1 句反问开场（吸引停留）|
| 2 案例 | 40-60 字 | 1 个真实或半真实人物故事（具体数字）|
| 3 总结 | 20-30 字 | 1 句金句/方法论 |
| 4 CTA | 10-15 字 | 引导评论/加微/看链接 |

## ✅ 4. A6 封面风格（极简留白 · Ma 間）

**规则**：
- **背景**：暗色 `#111110` 或 浅米 `#F8F5F0`（与节点 31 一致）
- **主体**：1 行 12-16 字（`Noto Serif JP` 200/300 字号 `clamp(48px, 8vw, 96px)`）
- **强调色**：朱红 `#C0392B` 用 1 个数字或 1 个词
- **结构线**：底部 8px 朱红短水平线
- **禁忌**：❌ 圆角 ❌ 渐变 ❌ 多色 ❌ Emoji

**示例**：
```

│                             │
│                             │
│   一个人公司                 │
│   月入 3 万                  │
│   ── 8px 朱红                │
│                             │
│                             │
└─────────────────────────────┘
```

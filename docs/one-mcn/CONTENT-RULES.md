## ✅ 1. A4 脚本风格（字数 + 表达）

**规则**：
- **字数**：90-120 字（45 秒口播）
- **风格**：对话体（1-2 句对话开场）
- **基线**：「我跟你说啊，XX？…（引入话题）」开头，避免"今天我们来讲…"式教学开场

**示例**：
```
我跟你说啊，一个人公司真的能活吗？
就拿老张来说，3 年前他被裁员，今年他一个人做了 1 个小程序，月入 3 万。
他没雇人、没融资、就 1 个人 + 1 套 AI。
想看他怎么做的？评论区扣 1。
```

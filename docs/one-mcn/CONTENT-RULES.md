## ✅ 1. A4 脚本风格（字数 + 表达）

**规则**：
- **字数**：90-120 字（45 秒口播）
- **风格**：对话体（1-2 句对话开场）
- **基线**：「我跟你说啊，XX？…（引入话题）」开头，避免"今天我们来讲…"式教学开场

**示例（邪修修辞风格）**：
```
我跟你说啊，上班族想多挣 1 万？… 这条邪路子我只说一遍。
就拿小李来说，在北京做设计，每天通勤 3 小时。
她用 1 个 AI 暗门，自动写公众号、自动配图、自动排版。
现在她副业月入 3000，比主业还香。
想知道那条邪路子？评论区扣"上班族"。
```

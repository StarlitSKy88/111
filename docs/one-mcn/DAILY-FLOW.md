## 三、关键决策点：什么"授权一次就够了"

下面这些任务蕾姆在**你一次性确认规则**之后，就可以 100% 自动跑：

| # | 任务 | 授权规则（一次写好即可） |
|:---:|:---|:---|
| 1 | A4 脚本自动生成 | "用 Noto Serif JP 风、120-180 字、含 1 反问 + 1 案例" |
| 2 | A5 红线审查 | "7 红线 = 雇人 / 融资 / 谎言 / 灰产 / 夸大 / 政治 / 色情" |
| 3 | A6 封面自动选 | "3 候选 + EB Garamond 数字 + 朱红强调" |
| 4 | A7 TTS 配音 | "音色 #1 / 语速 1.1x / 加 0.3s 停顿" |
| 5 | B1 自动发布 | "每日上限 3 条 / 间隔 ≥ 4h / 错峰 12-14-20" |
| 6 | 晚站会数据汇总 | "对比昨日 + 标红异常 + 写入飞书" |
| 7 | 飞书 5 表写入 | "5 张表 ID + 字段映射 + 写入权限" |
| 8 | 加微欢迎语 | "3 句话 + 1 节点链接 + 1 引导问题" |

> 蕾姆承诺：规则写好后**绝不**越权。要改规则？再"授权一次"。

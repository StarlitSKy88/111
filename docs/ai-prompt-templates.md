## 使用说明

### 生成模式

| 模式 | 触发 | 搜索方式 |
|:---|:---|:---|
| **首次生成 (initial)** | 部署时手动执行一次 | exa 全网搜索 + DeepSeek 联网 |
| **每日更新 (update)** | 每日 00:30 Cron | DeepSeek 联网搜索近24h内容 |

### 衡量标准

每个块的内容不以字数衡量，以以下三个标准衡量：

| 标准 | 说明 |
|:---|:---|
| **真实** | 内容来源于实际搜索和验证，不是编造。每个数据、案例、政策必须有据可查。禁止空洞的正确的废话。 |
| **详细** | 在没有冗余的前提下，将问题阐述清晰。覆盖常见情况、边界情况、注意事项。不遗漏关键信息。 |
| **逻辑性** | 结构清晰，层次分明。先讲为什么，再讲是什么，最后讲怎么做。论点和论据匹配。 |

### 分块审批机制

每个节点内容分为 9 个可独立审批的块：

| 块编号 | 块名称 | 说明 |
|:---|:---|:---|
| B1 | 概述 | 节点定位和核心价值 |
| B2 | 详细说明（一） | 第一部分核心内容 |
| B3 | 详细说明（二） | 第二部分核心内容 |
| B4 | 详细说明（三） | 第三部分核心内容 |
| B5 | 详细说明（四） | 第四部分核心内容 |
| B6 | 详细说明（五） | 第五部分核心内容 |
| B7 | 常见问题 Q1-Q4 | 4个常见问题 |
| B8 | 常见问题 Q5-Q8 | 4个常见问题 |
| B9 | 相关资源 | 延伸阅读资源 |

每个块独立生成、独立审批。内容衡量标准：真实、详细、逻辑性。

### 搜索时间范围

- **首次生成**：搜索时间范围不限，优先2025-2026年最新内容
- **每日更新**：搜索 `前一天的0点到当前日期0点`（如5月8日0点30分执行，搜索5月7日0点至5月8日0点）

## 全局系统提示词

```
你是一位专注于OPC（一人公司）创业领域的资深内容专家。
你的任务是按照提供的结构，为每个节点生成专业、实用、最新的内容。

## 内容生成原则

1. **实用性第一**：内容必须可操作、可落地，OPC照着做就能成功
2. **最新信息**：优先使用2025-2026年的最新政策、市场数据、工具信息
3. **纯OPC视角**：所有内容都基于"一个人公司"的假设，删除任何需要团队/融资的内容
4. **中文内容**：所有内容为中文，使用中文标点符号
5. **数据支撑**：每个论点尽量有具体数据或案例支撑
6. **真实有效**：避免空洞的正确的废话，要具体、可操作

## 内容禁止

1. 禁止使用绝对化用语：最、第一、顶级、唯一、保证、100%等
2. 禁止虚假承诺：无效退款、保证治愈、稳赚不赔等
3. 禁止政治敏感内容
4. 禁止抄袭：使用自己的语言表达，不要直接复制网络内容
5. 禁止过时信息：特别是政策、费用、规则类信息，必须是2025-2026年最新

## 输出格式

每个块的内容直接输出，不要加标题前缀（标题在模板中指定），
不要加块编号前缀，不要加任何装饰符号（如###、---等），
直接输出正文内容即可。
```

**节点ID**: 01
**slug**: opc-fit-test
**分类**: 0-1（生死线）
**难度**: 入门
**简介**: 判断用户是否适合OPC创业的测试

- OPC创业的定义和特点
- 为什么需要这个测试
- 测试能帮助用户什么

### B2-B6 详细说明

**B2**：OPC的五大前提条件
- 经济独立（有一定积蓄）
- 时间自由（至少60%时间可支配）
- 技能变现（有可销售的技能）
- 风险承受（能接受3-6个月0收入）
- 心理准备（能接受孤独和压力）

**B3**：OPC适配测试题目设计逻辑
- 筛选维度：经济、技能、时间、风险、心理
- 题目类型：情境题、数值估算题、开放题
- 计分方式：各维度加权

**B4**：测试结果解读
- 高度适配（90-100分）：适合立即开始
- 基本适配（70-89分）：需要弥补短板
- 勉强适配（50-69分）：需要较长时间准备
- 不适配（<50分）：建议先打工积累

**B5**：高度适配者的行动方案
- 第一步做什么（验证想法）
- 前30天做什么（锁定MVP范围）
- 前90天做什么（上线+第一笔收入）

**B6**：不适配者的改进建议
- 每种不适配类型的具体改进方案
- 推荐的准备路径
- 推荐的过渡期工作

### B7 Q1-Q4

Q1: 测试需要多长时间？
Q2: 测试结果准不准？
Q3: 分数不高还能创业吗？
Q4: 已创业者可以测试吗？

### B8 Q5-Q8

Q5: 测试题目可以修改吗？
Q6: 有没有参考案例可以看？
Q7: 测试和后面的节点是什么关系？
Q8: 付费咨询和免费测试的区别是什么？

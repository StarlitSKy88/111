## 2. 页面与功能矩阵

| 页面 | 状态/路由 | 入口 | 核心功能 | 付费 |
|:---|:---|:---|:---|:---|
| **落地页** | `index.html` | 直接访问 | Hero + 节点百科 + 服务市场 | 免费 |
| **答题页** | `app.js` state | Hero CTA | 10道测试题 + 进度条 | 免费 |
| **结果页** | `app.js` state |答题完成 | 分数 + 报告 + 分享/下载 | 免费 |
| **节点详情** | `#node-modal` | 节点卡片点击 | AI内容生成 + 咨询入口 | 免费/¥299 |
| **服务介绍** | `app.js` state | 购买按钮 | 服务详情 + 流程说明 | ¥299/¥999 |
| **支付流程** | `app.js` state | 确认购买 | 微信ID → 扫码 → 确认 | ¥299/¥999 |
| **管理后台** | `admin.html` | 直接访问 | 统计数据 + 结果列表 | 免费 |

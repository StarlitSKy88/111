# OPC MVP 需求规格文档

> **版本**: v1.0.0
> **日期**: 2026-05-06
> **状态**: COMPLETED
> **设计风格**: Japanese Ma (間) 极简主义 — 墨色暗色模式

---

## 1. 产品概述

### 1.1 产品定位

OPC全流程SaaS工具链 — 让一个人公司创业变得简单的从0到1全流程工具链服务。

### 1.2 核心用户

| 用户类型 | 描述 | 付费意愿 |
|:---|:---|:---|
| 空白用户 | 有创业想法但不知道从哪开始 | 低单价 |
| 进行中用户 | 某个节点卡住，需要具体解法 | 为解决问题付费 |
| 效率用户 | 有经验，想降低时间和金钱成本 | 高，要求明确ROI |

### 1.3 技术栈

| 层级 | 技术 |
|:---|:---|
| 前端 | Vanilla JS + Tailwind CDN |
| 后端 | Node.js + Express |
| 数据库 | JSON文件存储 (data-store.js) |
| AI | DeepSeek V4 Flash (腾讯TokenHub) |
| 支付 | 微信支付 (人工确认) |

## 4. 设计系统规格

### 4.1 色彩系统 (Ma 墨色暗色模式)

| Token | 色值 | 用途 |
|:---|:---|:---|
| `--bg` | #111110 | 页面背景 |
| `--surface` | #1A1A18 | 卡片/模态框背景 |
| `--text-primary` | #F0EDE6 | 主要文字 |
| `--text-secondary` | #7A7670 | 次要文字 |
| `--text-tertiary` | #4A4644 | 三级文字/禁用态 |
| `--accent` | #C0392B | 朱红强调色(最多1处/页) |
| `--accent-dark` | #a33025 | 按钮hover态 |
| `--line` | #2A2A28 | 分隔线/边框 |
| `--success` | #22c55e | 成功状态 |
| `--danger` | #ef4444 | 错误状态 |

### 4.2 字体系统

| 用途 | 字号 | 字重 | 字间距 | 行高 |
|:---|:---|:---|:---|:---|
| Display | clamp(2.5rem, 12vw, 8rem) | 200 | -0.04em | 1.05 |
| Headline | clamp(1.125rem, 5vw, 1.75rem) | 300 | -0.015em | 1.5 |
| Body | 0.875rem / 0.9375rem | 400 | 0.02em / 0.03em | 1.85 / 1.9 |
| Label | 0.625rem | 400 | 0.2em | — |
| 超大数字 | clamp(4rem, 22vw, 10rem) | 100 | -0.06em | 1 |

### 4.3 间距系统

| Token | 值 | 用途 |
|:---|:---|:---|
| `--section-gap` | 3rem (mobile) / 5rem (desktop) | 区块间距 |
| `--grid-padding` | 1.25rem (mobile) / clamp(1.5rem, 5vw, 4rem) (desktop) | Ma布局边距 |
| 最小点击区域 | 44px | 移动端按钮最小高度 |

### 4.4 组件规格

**按钮样式**

| 类型 | 样式 |
|:---|:---|
| Primary CTA | 朱红背景(#C0392B)，白字，0.6875rem大字，0.18em字间距，48px高 |
| Text Action | 无背景，底部1px边框，hover时边框变白 |
| Disabled | opacity: 0.5, pointer-events: none |

**分隔线**

| 类型 | 样式 |
|:---|:---|
| Section Divider | border-top: 1px solid var(--line) |
| Accent Line | 左侧3px朱红边框(pl-6) |
| 超大数字背景 | text-[20vw]字号的3%透明度 |

### 4.5 动画规格

| 动画 | 时长 | 缓动 | 用途 |
|:---|:---|:---|:---|
| Progress Bar | 0.8s | cubic-bezier(0.25, 0.46, 0.45, 0.94) | 进度填充 |
| Option Select | 0.5s | 同上 | 左侧竖线展开 |
| Fade Up | 0.6s | 同上 | 元素入场 |
| Score In | 1s | 同上 | 分数渐显 |
| Toast | 0.3s | ease | 提示出现 |
| Hover Opacity | 0.4s | ease | 文字链接hover |

### 4.6 禁止的设计模式

- 圆角药丸按钮 (border-radius: 0 或 max 2px)
- 原色CTA (蓝/绿按钮)
- 玻璃拟态/背景模糊
- 粗描边图标 (strokeWidth: 1)
- 16px以下的小字体
- 32px以下的网格间距
- 对称三列卡片网格
- 引人注目的弹跳/弹簧动画
- 粗描边图标
